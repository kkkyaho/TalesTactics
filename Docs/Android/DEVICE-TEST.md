## 2. 화면과 첫 전투 조작

- [ ] 타이틀 → 새 테스트 슬롯 → 거점 → 첫 캠페인 전투까지 실제 손가락으로 진행한다. 대사 넘김, 편성, 장비·설정 진입과 돌아가기가 막히지 않는다.
- [ ] 가로 양방향에서 타이틀·거점·대화·전투의 주요 문구와 버튼이 노치·시스템 영역에 가리지 않는다. 기본 글자 크기와 1.3배에서 잘림·겹침을 확인하고 실제 화면을 기록한다.
- [ ] 한 손으로 이동·공격·기술·확정·취소·방향 선택을 누른다. 옆 버튼 오입력이나 작은 터치 영역이 있으면 화면·버튼 이름과 재현 횟수를 적는다.
- [ ] 이동할 칸을 탭하면 경로가 보이고, 같은 칸을 반복 탭해도 이동하지 않는다. **확정 버튼**을 눌렀을 때만 이동하며 취소 후 다른 칸을 새로 선택할 수 있다.
- [ ] 적을 선택해 공격 예측을 보고 취소한 뒤 다시 선택·확정한다. 공격과 사용 가능한 기술 하나가 각각 한 번만 실행되고 HP·MP가 결과에 맞게 변한다. 아직 기술을 사용할 수 없으면 이유와 후속 검사 지점을 남긴다.
- [ ] 기술 목록은 한 페이지 최대 3개이며 페이지 이동·상세·취소가 작동한다. 선택 취소 뒤 이전 대상이나 경로가 다음 행동으로 실행되지 않는다.
- [ ] 한 손가락 드래그로 전장을 움직이고 두 손가락으로 확대·축소한다. 손가락을 놓거나 하나를 바꿔도 공격·이동이 실행되지 않는다.
- [ ] UI 버튼·도움말에서 시작한 손가락을 전장으로 끌어 놓는다. UI와 전장이 동시에 반응하지 않고, 앱 복귀 후 남아 있던 접촉도 새 명령으로 처리되지 않는다.

각 실패에는 단계·기대 결과·실제 결과·재현 횟수와 로컬 캡처 경로를 남긴다. 첫 전투의 확인만으로 전체 40전투·10대화의 화면 검증을 완료 처리하지 않는다.

## 3. 앱 전환·종료와 저장 복구

대상은 **훈련·튜토리얼을 제외한 캠페인**이다. 복구 기준은 저장에 성공한 마지막 아군 명령 경계이며, 선택 화면이나 진행 중인 연출 자체를 복원하는 기능이 아니다. 첫 저장부터 실패했다면 해당 전투의 이어하기는 보장되지 않는다.

- [ ] 아군 명령 화면에서 저장 실패 안내가 없는지 확인하고, 턴·활성 캐릭터·위치·HP/MP·금액·보유 아이템을 기록한다. 이동 또는 공격 완료 후 다음 명령 화면의 상태도 따로 기록한다.
- [ ] 명령 화면에서 다른 앱으로 전환했다가 돌아온다. 상태와 조작이 유지되고, 탭을 다시 시작하기 전 행동이 저절로 실행되지 않는다.
- [ ] 명령 화면에서 **테스트 앱만 강제종료**하고 다시 실행해 이어하기를 선택한다. 기록한 마지막 저장 상태가 복구된다. 앱 데이터 삭제·저장 덮어쓰기는 하지 않는다.
- [ ] 이동 연출·공격 연출·적 턴·대상 선택 중 종료를 각각 시도한다. 직전 저장 성공 경계로 돌아오며, 중간 이동 좌표·절반 적용된 피해·중복 행동이 남지 않는다. 종료 전에 이미 명령 화면에 도달했다면 그때 저장된 상태를 기준으로 판단하고 종료 시점을 기록한다.
- [ ] 전투 전 대화 중 종료 후 해당 전투에 다시 진입하면 대화가 처음부터 시작한다. 전투 후에는 보상을 받은 뒤 금액·아이템을 기록하고, 종료 대사를 한 줄 넘겨 종료·재실행한다. 저장된 대사 줄을 이어 읽으며 반복 재실행으로 보상이 늘어나지 않는다.
- [ ] 저장 실패 안내가 나타나면 화면과 시점을 남긴다. 현재 진행을 저장 성공으로 기록하지 않고 기존 저장이 유지되는지 확인한다. 이 검사를 위해 기기 저장 공간을 임의로 채우거나 사용자 파일을 손상시키지 않는다.

## 4. 음악 복귀와 20분 연속 실행

- [ ] 실제 스피커 또는 이어폰으로 타이틀·거점·전투 음악과 효과음을 듣는다. 앱 전환·화면 잠금 후 복귀 때 무음 고착·이중 재생·음량 급변이 없는지 확인한다. 다른 앱의 소리 재생 후 돌아오는 경우도 구분해서 기록한다.
- [ ] 약 20분 동안 전투·기술 연출·메뉴 이동을 반복한다. 시작·5분·10분·20분의 게임 FPS와 긴 끊김, 배터리 잔량·발열 상태를 같은 조건에서 기록한다. 측정 도구가 제공하면 프레임 시간·메모리·온도도 함께 적는다.
- [ ] **30fps는 설정 목표이며 보장 성능이 아니다.** 화면 주사율을 게임 FPS로 대신 쓰지 않는다. 측정 도구가 없으면 체감만 적고 수치 항목은 미측정으로 남긴다. 후반 프레임 저하·입력 지연·강제 종료·음악 끊김 여부를 확인한다.
