# 실제 화면 시각 검수

최종 동료10명의 대표 원본을 직접 확인했다. 고유 모션195장·전장44장(중복 제거239장)이며, 전체5,539모션·80전장을 모두 수동 승인한 결과는 아니다. [원문 해시와 확인 범위](visual-review.json) · [선택한 실제 화면](../Evidence/gallery.html).

Palette discipline: 4/5 — 캐릭터 고유색과 외곽선이 기존 전장의 낮춘 색 대비와 구분된다. 6화 회전·확대 화면에서 의상과 무기를 식별했다.
Style uniformity: 4/5 — SD 비례·명암·외곽선을 유지하고 새18장과 알펜 시범 원화의 보이는 몸체 높이를 맞췄다.
Lighting depth: 3/5 — 실제 발 접촉·몸 그림자와 포즈별 피벗으로 접지를 확인했다. 배경의 세부 밀도와 다른 전장 지형의 광원 조정은 후속 범위다.
Silhouette: 4/5 — 활·지팡이·창·손날·검·총·철퇴·방패가 전후좌우 방향에서 잘리지 않고 구분된다.
UI intentionality: 4/5 — 실제 전장 회전과1280/2340가로 화면에서 HP바가 무기 끝이 아닌 머리 위를 따른다. 실제 휴대폰 글자 크기·터치 검수는 별도다.
Feedback visibility: 4/5 — 호흡·눈감음·준비/타격/회수·붉은 피격·새 대기 복귀가 실제 관측 프레임에 나타난다. 모든 고유 기술의 새 프레임은 이번 범위가 아니다.

첫 좌표 후보에서 장식/무기를 머리로 잡거나 정강이를 발로 잡은 부분을 수정했고, 캐릭터별 대기 시점 차이를 적용한 뒤 최종 원화와 실제 화면을 확인했다. 확대·투명도 수정 등 원본 PNG의 픽셀 보정은 하지 않았다.

[실제 재질·글꼴·진행 프레임](palette-and-live-frames.json): 기본/빈/오류 재질0, 활성 기본 글꼴0, Unity 실제320프레임 진행과 콘솔 오류/경고0을 관측했다. 흰색/회색 UI 후보1개인 능력은 alpha0의 투명 입력 영역이며 보이는 미스타일 패널이 아니다. 관측값을 지우지 않고 해석을 구분했다.
