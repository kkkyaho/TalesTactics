# 행동 경험치 — 2026-10-12

캠페인에서 행동한 캐릭터가 경험치를 얻는다. 100 EXP마다 레벨업하며 최고 레벨은 50이다. 영걸전·조조전의 행동별 성장과 레벨 차이 보정 방향을 참고한 자체 수치이며 원작 공식을 복제한 것은 아니다.

| 유효 행동 | 동레벨 기준 |
|---|---:|
| 일반 공격 | 12 |
| 공격 기술 | 16 |
| 회복 | 실제 회복량에 따라 6–18 |
| 새 아군 강화·게이지 지원 | 10 |
| 실제 상태이상 해제 | 14 |
| 부활 | 24 |
| 적 처치 | 해당 공격에 +24 |
| 임무 보스 처치 | 해당 공격에 +40 (일반 처치 보너스 대체) |

- 레벨 배율은 `clamp(1 + 0.2 × (대상 레벨 - 행동자 레벨), 0.2, 2)`. 아군 지원의 상한은 1.5배다.
- 같은 기술의 여러 타격은 대상별로 합산해 한 번 지급한다. 한 대상에 여러 효과가 있으면 가장 높은 행동 보상을 사용하고 처치 보너스만 더한다. 범위 기술은 경험치가 높은 대상부터 100% / 50% / 이후 각 25%로 합산한다.
- 일반 공격/공격 기술의 최대 기본 보상은 대상 최대 HP의 10% 이상을 실제로 깎았을 때다. 그보다 작은 피해는 비례 감소한다(기본 보상의 최소 10%). 회복은 최대 HP의 50% 회복에서 18, 최대 HP의 5%보다 작은 회복은 추가 감액한다. 무효·초과 회복, 중복 버프, 해제할 상태가 없는 해제는 0이다.
- 반격·자동 지원 공격은 위 계산의 50%. 실제로 마지막 피해를 준 캐릭터만 처치 보너스를 받는다. 적 캐릭터와 훈련/입문 연습은 경험치를 얻지 않는다. 상태 지속 피해·방어·대기에는 경험치가 없다.
- 본 행동과 지원·반격 계산을 모두 끝낸 뒤 레벨업한다. 생존자는 최대 HP/MP 증가분만 회복하고, 전투불능자는 부활하지 않는다. 예측은 복제한 전투를 계산하며 실제 경험치를 변경하지 않는다.

## 저장과 UI

- 행동 경험치는 전투 중 임시 성장이다. 승리하면 전투불능 아군을 포함해 각자의 획득량과 최초 임무 보너스 30(반복 10)을 함께 확정한다. 저장 실패 시 전체 보상을 복원하며 재시도는 한 번만 지급한다.
- 중단/이어하기는 현재 레벨·EXP·전투 획득량을 보존한다. 행동 되감기는 해당 행동 이전으로 모두 복원한다. 재도전은 출전 당시 성장으로 돌아가며, 포기·패배는 미확정 성장을 캠페인에 반영하지 않는다.
- 저장 스키마 1/2 → 3으로 읽을 때 기존 레벨과 경험치 진행률을 유지한다(예: Lv5 250/500 → 50/100, 소수점 버림). 첫 저장 시 원본을 `.v1.bak` / `.v2.bak`로 추가 보존한다. 읽기만으로 파일을 다시 쓰지 않는다. 구버전 실행 파일로 새 저장을 열면 기존 미래 버전 보호가 작동한다.
- 구버전 중단 전투(v1–8)/출전 기록(v1–3)은 행동 경험치를 끈 채 복원한다. 해당 기록을 재도전해도 출전 규칙을 유지하고, 새로 출전하면 새 규칙을 사용한다. 새 체크포인트는 v9, 출전 기록은 v4다.
- 전장에는 `EXP +n`, 레벨업 때만 `Lv UP a → b`를 1.3초 표시한다. 별도 확인창은 없다. 결과에는 캐릭터별 실제 총 획득량과 레벨 변화, 성장 화면에는 100 기준 막대를 표시한다. 자세한 규칙은 도움말에 둔다.

기존 합류 훈련·캠페인 기술 숙련·6장 궁극기 체험은 유지한다. 전투를 빨리 끝내거나 행동하지 않은 캐릭터는 행동 경험치가 적으므로 합류 훈련으로 권장 출전 레벨을 맞출 수 있다.

## 재현

- Unity Test Runner: `ActionExperience` / `Experience` 필터와 전체 EditMode/PlayMode.
- `Tools/ReviewExperienceProgression.ps1`: 실제 에셋·합법적 AI 행동으로 6장을 연속 시뮬레이션. 합류 훈련 사용 여부를 나누며 행동/지원 횟수와 캐릭터별 성장을 기록한다. 패배 시 그 경로를 중단한다.
- `Tools/ReviewActionExperience.ps1`: Play Mode에서 격리 저장 경로를 사용해 3해상도×2글자 크기×4화면을 검사한다. 레벨업 표시 캡처 중에만 시간을 정지한다.

검증 증거와 한계는 `Docs/VALIDATION.md`의 최신 행동 경험치 항목을 따른다. 자동 전투 결과는 사람의 난이도·장기 성장 속도 평가를 대신하지 않는다.

## 6장 성장 시뮬레이션

`progression.json`은 실제 Unity 에셋과 합법적 AI 행동으로 계산한 결과다. 합류 훈련 없이 6장 모두 승리했으며 종료 레벨은 크레스4 / 민트5 / 키사라2 / 제이드8 / 시온5 / 파라8이었다. 행동 횟수가 적었던 키사라는 뒤처졌고, 지원 캐릭터 민트도 유효 지원과 공격으로 성장했다. 권장 레벨 합류 훈련을 사용한 별도 경로도 6장 모두 승리했고 종료 레벨은 7 / 7 / 7 / 8 / 7 / 8이었다.

이는 한 추천 편성과 고정 AI 경로의 결과다. 모든 조합의 성장 균형을 증명하지 않으며, 먼저 행동하는 원거리/범위 캐릭터와 행동하지 못한 전열 사이의 격차는 사람의 플레이로 추가 평가할 항목이다. 이번 적용에서는 합의한 지급 수치와 기존 합류 훈련을 유지했다.
