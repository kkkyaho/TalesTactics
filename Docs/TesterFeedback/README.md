# 플레이 테스트 피드백 반영

테스터 의견 중 조작 발견성과 상태 안내의 혼동을 개선했다. 출전하지 않은 캐릭터가 남은 행동에 포함되는 원인은 확인되지 않았고, 실제 출전 유닛의 이동/행동과 방향 확정 대기를 구분한다.

| 항목 | 적용 방식 |
|---|---|
| 전장 이동 | 가운데 마우스 버튼 드래그. 맵 밖 무제한 이탈 방지, 휠 확대·축소와 Q/E 회전 유지, Home 초기화. UI 위에서 드래그를 시작하지 않는다. |
| 턴 종료 | 실제 출전 인원만 표시. 이동·행동 남음, 이동만 남음, 행동 남음, 방향 확정 대기, 행동 불가를 구분한다. 이동 금지/기절/수면 및 연계 가능 여부를 반영하며 자동으로 턴을 소비하지 않는다. |
| 적 기술 | 명령 대기 중 적을 클릭하면 요약과 기술 보기. 임무 적 상세에서도 같은 기술 목록으로 연결한다. 준비 단계는 별도 규칙 스냅샷으로 보스/난이도/전술 기술을 반영한다. |
| 보상 | 아이템 카드를 클릭하면 능력치·효과·획득/보유 수량·합류한 장착 가능 동료 표시. 보상 재지급이나 자동 장착 없이 결과로 돌아가며 필수 후일담 순서를 유지한다. |
| 장비 | 현재 장착/선택 초안/다른 동료 착용 중과 미장착 수량 표시. 다른 동료가 마지막 하나를 착용해도 비활성 후보로 보이며 강제로 빼앗지 않는다. |
| 레벨업 | 기존 중앙 EXP 카드 안에서 0.7초 상승 빛과 효과음. 하나의 경험치 알림당 한 번만 재생하고 축소 효과·음량·모달 대기를 준수한다. |

기존 도움말 12페이지에 새 조작을 통합했다. 상단 도구 버튼, 화면 가장자리 자동 스크롤, 별도 레벨업 확인창은 추가하지 않았다. Core/Content 데이터나 저장 형식을 바꾸지 않는다.

## 검증 — 2026-10-18

- 실제 Unity 6000.6.0f1 전체 PlayMode **218/220, 530.86초**. 실패 2개는 테스트 전제(이동 선택 중 열 수 없는 시스템 메뉴)와 대기 시점(레벨 숫자가 먼저 변하는 애니메이션) 문제였다. 수정 후 카메라 **1/1, 4.95초**, 레벨업 **3/3, 14.82초** 통과. 최종 레이아웃 보완 뒤 피드백 기능 **10/10, 25.34초** 및 장비 **8/8, 16.04초** 추가 통과. 최종 단일 전체 220/220 실행으로 표현하지 않는다. 초기 실패와 후속 결과를 모두 Validation에 보관했다.
- Runtime/Editor/EditMode/PlayMode 4개 API 참조 컴파일 통과. 코어 규칙 변경이 없어 이번 EditMode/ManagedChecks 실행은 하지 않았다. 실제 Unity PlayMode와 API 컴파일을 구분한다.
- Editor Game View **80상태 × 5해상도 × 3글자배율 = 1,200/1,200**, 오류0. 1280×720, 1024×768, 1920×1080, 2560×1080, 1080×1440 및 글자100/115/130%. 초기 92조합에서 장비의 3줄 정보와 긴 적 설명 넘침을 발견하여 행 높이·설명 공간을 수정했다. 프레임 진행을 확인한 실제 렌더링이며 캡처8장을 보존했다.
- 위 Editor 전체 검수 후 보스 요약에서 일반 병사 조언을 제외하는 문구 조건을 마지막으로 보완했다. 해당 최종 소스는 별도 Windows 검수 실행본 **1902×991 × 3글자배율 × 80상태 = 240/240**, 오류/예외 로그0으로 확인했다. 초기 Windows 22조합 문제도 보존했다. 검수 프로세스의 종료를 확인했으며 종료코드를 별도 OS 핸들로 수집하지는 않았다.
- 최종 일반 Windows 빌드 **37.289초**, 검수 빌드 **21.646초**, 각각 오류0/경고2. 경고는 기존 Pipeline 런타임 미설정 및 `VfxUpgradeReview.cs`의 DEVELOPMENT_BUILD 지시문 사용 중단 안내다. 최초 검수 빌드의 URP 내부 디버그 셰이더 stripping 경고도 원시 보고서에 보존했다. 일반 DLL에서 검수 타입 제외 확인. 일반 실행 파일을 별도 시작하지 않았으며 실제 Windows 실행 검증은 검수 빌드 범위다.
- 사용자 저장·백업·설정 **8파일 SHA256 불변**. 수정된 Assets29파일 C/D 해시 일치. 전체 소스 감사는 추적1245파일+신규14파일을 확인했고, 직렬화 공백 및 동적 TMP 글꼴 캐시를 제외한 코드·가져오기 설정 차이는 없었다. 동적 글꼴 캐시는 원본 설정이 같고 빌드 시 초기화된다.
- 최종 Play=false, Scene dirty=false, 컴파일 실패 없음, runInBackground=false 및 원래 빠른 Play 옵션 복원. 개발 검수는 모두 격리 저장을 사용했다. 다른 PC/DPI, 물리 마우스 기종, 효과음 실청취, 전체 캠페인 수동 완주와 장시간 성능은 검증 범위 밖이다.

실행 파일: `D:/TalesTacticsHelpGuide/Builds/TesterFeedbackWindows/TalesTactics.exe`.
