# 캠페인: 경계의 빛

이 프로젝트를 위해 작성한 창작 시나리오다. 기존 캐릭터가 유적·관측소·수문·중계핵을 조사하는 6장 이야기를 구성하며, 원작의 사건이나 대사를 재현한 것은 아니다. 최종 배경 아트·캐릭터 초상화·음성은 후속 작업이다.

## 1장 — 유적의 경계

- 장소: 유적 외곽 · 갈라진 물길. 11×9 타일, 동쪽 높이 1.
- 지형: 중앙 물길, 남쪽 돌다리와 북쪽 우회로, 통로 주변 장애물.
- 배치: 서남쪽 아군 최대 6명, 동쪽 수호병 4명(Lv1).
- 이야기: 마을까지 번진 진동을 조사하던 일행이 물길 너머의 부적을 발견한다. 외곽 수호병을 물리친 뒤 부적이 심층 제단과 연결되어 있음을 알아낸다.
- 목표: 모든 적 격파. 최초 출전 전원 EXP120/120G, 반복 EXP60/60G, 생명의 부적1개. 추가 청동검25%/가죽 갑옷15%/없음60%.
- 완료: 2장과 철검·강화 갑옷 상점 해금. 전투 후 대사 다시 읽기 가능.

## 2장 — 유적의 수호자

- 장소: 심층 제단 · 수호자의 계단. 12×10 타일, 높이 0→1→2의 계단.
- 지형: 중앙 접근로, 양옆 기둥, 북쪽 고지의 제단.
- 배치: 남쪽 중앙 아군 최대 6명, 제단 양쪽 수호병 4명(Lv3).
- 이야기: 불안정한 제단의 빛 때문에 깨어난 수호병을 제압한다. 부적을 제단에 되돌려 진동을 잠재우고, 남겨진 기록을 가지고 마을로 돌아간다.
- 목표: 모든 적 격파. 최초 출전 전원 EXP180/180G, 반복 EXP90/90G, 철검1개. 추가 청동검25%/강화 갑옷15%/없음60%.
- 완료: 유적 이야기 종결과 3장 해금. 기존 승급의 스토리 조건 충족(레벨 조건은 별도).

## 3장 — 협곡의 봉화

13×10 협곡, 두 돌다리·동쪽 능선. 적4명 Lv4. 최초 EXP300/240G, 반복150/120G, 강화 갑옷1개. 봉화를 복구하고 관측소를 향한다.

## 4장 — 별을 읽는 탑

12×12 관측소, 남쪽 회랑에서 북쪽 높이2 관측단으로 진입한다. 기둥 사이에서 사격 시야를 확보한다. 적4명 Lv5. 최초 EXP600/320G, 반복300/160G, 수호의 메달1개. 봉화에 응답한 것은 사람이 아닌 자동 관측반이었으며, 옛 명령이 저수 시설에서 반복되고 있음을 알아낸다. 5장과 수호의 메달 상점을 해금한다.

## 5장 — 잠긴 수문

14×10 저수 시설. 남북 교량으로 두 물길을 건너 동쪽 고지에 접근한다. 적4명 Lv6. 최초 EXP900/420G, 반복450/210G, 단련 갑옷1개. 갇힌 관리인들을 구하고 명령의 근원을 중계탑으로 좁힌다. 6장과 단련 갑옷 상점을 해금한다.

## 6장 — 새벽의 중계핵

13×13 원형 단상, 높이0→1→2의 동심 지형과 네 기둥. 적4명 Lv8, 보스 음악. 최초 EXP1500/560G, 반복750/280G, 수호의 메달1개. 수호병을 제압하고 새 관측 신호를 전해 반복 명령을 끊는다. 일행이 마을로 귀환하며 첫 여정이 완결된다. 구현 범위는6장까지이며7장은 없다. 완료한 장은 계속 도전할 수 있다.

모든 장의 목표는 적 전멸이다. 2~6장은 청동검25%/강화 갑옷15%/없음60% 추가 드롭을 유지한다. 6장의 보스 음악은 별도 보스 유닛/특수 목표가 추가되었다는 뜻이 아니다. 전후 대사는 장마다5개(1장 후일담4개)다.

## 진행과 저장

출전 준비 → 전투 시작 → 전투 전 이야기 → 전투 → 승리/보상 저장 → 전투 후 이야기 → 출전 준비.

- 출전 화면의 이전/다음 장 목록으로3개씩 탐색한다. 목록 페이지만 넘기면 출전할 장은 바뀌지 않는다. 원하는 장 버튼을 눌러 선택한다.
- 다음 대사, 마지막 대사에서 마치기, 전체 건너뛰기를 지원한다.
- 출전 화면에서 전투 전 이야기를 다시 읽을 수 있다. 후일담은 해당 장 완료 후 읽을 수 있다.
- 대사 조회/건너뛰기는 골드·장비·완료 기록을 변경하지 않는다.
- 보상 저장 실패 시 후일담은 잠기고 보상 재시도를 제공한다.
- 대사 진행 위치와 전투 중간 상태는 저장하지 않는다. 재시작하면 출전 화면에서 시작한다.
- 훈련은 원래 10×9 테스트 맵을 사용하며 이야기를 자동 표시하지 않는다.
- 반복 승리는 기존 보상 정책을 유지한다. 장비 99개 상한은 결과 화면에 안내한다.
