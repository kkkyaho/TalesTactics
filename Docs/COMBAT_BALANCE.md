## 저항/약점

미지정 속성·무속성은 ×1. 피해 배율0은 무효, 0~1은 저항, 1~2는 약점. 회복과 상태효과 확률에는 적용하지 않는다.

- 크레스 알베인: 모든 속성 중립
- 민트 아드네이드: 빛 ×0.75, 어둠 ×1.25
- 벨벳 크라우: 어둠 ×0.75, 빛 ×1.25
- 파라 엘스테드: 모든 속성 중립
- 티아 그란츠: 빛 ×0.75, 어둠 ×1.25
- 제이드 커티스: 모든 속성 중립
- 나탈리아: 모든 속성 중립
- 알펜: 불 ×0.75, 물 ×1.25
- 시온 아이메리스: 모든 속성 중립
- 키사라: 모든 속성 중립
