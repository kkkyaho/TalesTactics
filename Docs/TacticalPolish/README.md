# 전술 시스템·UI 개선

신규 전투는 아래 규칙을 사용합니다. 튜토리얼과 V1–V3 중단 전투는 기존 규칙을 유지합니다.

- 자유 턴 생존: 아군 인원과 무관하게 적군 턴을 4회 마쳐야 승리합니다. 적이 전멸했다면 아군 턴 종료가 빈 적군 턴을 대신 집계합니다. SPD·CT는 기존 아군 개인 턴 종료 12회입니다.
- 턴 종료: 남은 인원 확인 후 전원 대기합니다. 방향 유지, 방어 효과 없음, 상태·쿨다운 처리 중복 없음. 취소하면 아무 행동도 소모하지 않습니다.
- 행동 표시: 상단에 이동·행동 / 이동 / 행동 / 대기 가능 / 완료를 표시합니다. 전장 발밑의 청록·파랑 꺾쇠는 미완료, 회색 가로선은 완료입니다.
- 기술 목록: 기본은 사용 가능한 기술. 상단 버튼으로 전체 조회하면 잠긴 기술도 상세 조건을 확인할 수 있습니다. 사용 불가 기술 클릭은 상세 조회만 하며 행동을 소모하지 않습니다.
- 민첩: 물리 피해에 공격자−방어자 SPD 차이 ×0.5%, 상한 ±15%. 마법에는 적용하지 않습니다. SPD·CT의 순서/빈도 효과는 유지합니다.
- 협공: 공격자와 다른 아군이 표적의 서로 반대인 인접 칸을 차지하면 물리 피해 +10%. 기절·수면·전투불능 동료는 참여하지 않습니다. 양 팀에 동일 적용합니다.
- 예측: 민첩·협공 수치와 최종 HP를 실제 실행과 같은 계산기로 표시합니다.
- 성장 방향: Lv10부터 돌파(공격·마력 +12%, 방어·마방 −8%) / 수호(방어·마방 +12%, 공격·마력 −8%) 선택. 무료 변경·해제 가능. 직업·고유 기술·기존 특성은 유지합니다.
- 프리셋: 출전 순서와 전체 캐릭터의 장비를 3슬롯에 보관합니다. 적용 시 현재 장착을 교체하고 저장합니다. 호환성·보유 수량을 검증하며 실패하면 기존 편성·장비를 유지합니다.

저장 외부 버전은 V2의 추가 필드로 유지하며, 중단 기록은 V4로 올립니다. 과거 중단 전투에 새 피해·생존 규칙을 강제로 적용하지 않습니다. 사용자 Content 에셋을 재생성하지 않습니다.

반격·지원 공격·전투 전체 되감기·증원 이벤트·난이도 프리셋은 이번 구현 범위에 포함하지 않습니다. 6장 전체를 사람이 여러 편성으로 완주한 난이도 평가는 별도로 필요합니다. 수치 상한과 자동 검증은 체감 난이도 검증을 대신하지 않습니다.

자동 캠페인 관찰: 권장6인·장별 권장 레벨·장비 없는 자동 AI에서 1–6장은 각각 총 행동 40/5/27/27/31/2회로 승리했습니다. 2장·6장은 첫 아군 페이즈에 보스가 쓰러졌습니다. 특히 6장의 궁극기 체험과 선제 집중 공격이 전투를 짧게 만드는 경향은 후속 보스 밸런스 과제입니다. 이 결과는 자동 정책 1종의 기능 관찰이며 사람의 난이도 평가가 아닙니다. 근거: `campaign-scenarios.json`, 재현: `Tools/ReviewTacticalBalance.ps1`.
