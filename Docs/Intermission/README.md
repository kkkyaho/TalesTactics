# 인터미션 메뉴 개편

승인된 장비 관리·상점·성장/승급 시안을 기존 출전 편성과 같은 남색·청록·황동 스타일로 적용했다. 기존 유적 배경·10인 초상화와 신규 장비 그림을 사용한다. 이미지의 버튼이나 숫자를 통째로 붙이지 않고 실제 카탈로그·저장 데이터를 읽는 uGUI로 구성했다.

## 화면과 조작

- 장비 관리: 캐릭터 초상/모델과 세 부위, 호환 보유 장비 목록, 9개 능력치의 교체 전후 비교. 사용 가능 수량·현재 장착 표시, 장비 해제, 후보 페이지, 적용/취소를 제공한다. 캐릭터나 메뉴를 바꾸면 미적용 변경은 취소된다. 슬롯별 목록은4개씩 표시한다.
- 장비 상점: 구매/매각 탭, 부위 필터, 3×2 아이템 카드,6개씩 페이지 이동, 보유/장착/미장착 수량, 거래 후 실제 잔액과 차단 사유. 1개 단위 거래와 저장 실패 복원, 잠금/훈련/저장 보호 규칙을 유지한다. 구매 후 캐릭터 초상 목록 → 장비 비교 → 별도 적용/저장으로 연결한다.
- 성장·승급: 저장된 레벨/EXP/장비 기준 능력치, 실제 직업명과 승급 전후9개 수치, 레벨·장 완료 조건, 합류 훈련. 전술 특성을 한 개 선택해 효과를 확인하고 ‘특성 적용 · 저장’으로 확정한다. 저장 실패 시 기존 특성과 없던 성장 기록까지 복원한다. 기술 숙련 설명은 별도 모달에 유지한다.
- 공통 상단으로 출전 편성·장비 관리·상점·성장·임무 정보를 오간다. 저장·설정/도움말과 기존 마우스·Tab/Submit·게임패드 포인터 경로를 재사용한다. 데이터 저장 형식, Content 수치, 전투 규칙은 변경하지 않는다.

## 아트

[EquipmentIcons 제작 프롬프트 및 ID 매핑](ART.md). 치유 휘장은 메달 아이콘을 공유한다. 시안의 예시 수치·가격·미구현 수량 화살표는 옮기지 않고 게임의 실제 값과1개 거래 규칙을 따른다.

## 검증

실제 Unity 전체 PlayMode93/93(188.74초), EditMode125/125(0.71초) 통과. 새3개 테스트는 포인터 기반 장비 선택/취소/저장 실패/재시도, 조회·특성 초안의 저장 불변, 실패한 새 기록 복원, 상점2페이지 거래 유지와 숙련 모달 입력 차단을 검증한다. 기존 특성 테스트는 선택→적용의 새 경로로 갱신했다. 자세한 결과는 playmode-results.json, editmode-results.json.

레이아웃 검수 중 찾은 이미지 AspectRatioFitter 영역 이탈과 작은 글자 높이를 보정했다. 최종 화면 검증은 아래 기록을 따른다.

최종 레이아웃 수정 뒤 관련 PlayMode **3/3(3.75초)** 재통과(`final-intermission-tests.json`). Runtime/Editor/EditMode/PlayMode의 실제 Unity API DLL 컴파일도 모두 통과했다. ManagedChecks는 이번에 실행하지 않았으며 Unity 결과로 대체하지 않는다.

`Tools/ReviewIntermission.ps1`은 별도 임시 저장 루트와 메모리 콜백으로 실제 Game View를 검수한다. 1024×768 /1280×800 /1366×768 /1920×1080 /2560×1080 × 글자100/130% × 장비·상점·성장·장착 대상의 **40조합**, 버튼 화면 이탈0건·활성 문구 넘침0건. 프레임6040→82516의 진행도 기록했다(`aspect-matrix.json`). 대표1024/1920/2560 화면을 직접 확인했다. 시각 증거는 Editor Game View이며 실제 Windows 물리 입력/실물 게임패드 검수를 뜻하지 않는다.

실제 Full HD 화면: [장비 관리](equipment-1920-1080-1.png), [상점](shop-1920-1080-1.png), [성장·승급](growth-1920-1080-1.png), [구매 후 장착 대상](recipients-1920-1080-1.png). PNG에 표시된 Lv19/골드1280은 검수용 격리 데이터이며 사용자 저장을 변경하지 않는다.

Windows 일반 빌드 **25.210초 / 오류0 / 경고10** 성공(`windows-build.json`). 기존 Pipeline·개발 전처리기·직렬화·셰이더/TMP 경고가 남는다. `Builds/WindowsIntermission/TalesTactics.exe`가 이번 실행 파일이며 데이터/DLL을 포함한 폴더 전체가 필요하다. 숨김 시작12초 동안 프로세스가 유지되었고 로그 오류/예외0건(`startup-check.json`, `windows-startup.log`, `build-hashes.json`). 실제 Windows 화면·물리 입력 검수는 포함하지 않는다.

사용자 campaign.json/.bak/.v1.bak의 SHA256은 전후 불변이며 새 슬롯/설정 파일을 만들지 않았다(`user-save-check.json`). 작업에서 실행한 플레이어만 종료했다. Play 종료·Full HD·runInBackground=false·Scene dirty=false를 복구하고 캡처 임시 에셋을 Temp로 이동,동적 폰트 캐시와 자동 검사 CSV를 복원했다(`editor-restored.json`). 공개 Release 배포는 이번 작업에 포함하지 않는다.
