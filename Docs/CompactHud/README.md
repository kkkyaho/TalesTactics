# 전투 선택창·캐릭터 정보창 개편

슈퍼로봇대전식으로 짧은 명령, 긴 기술 목록, 캐릭터 요약과 상세 정보를 나눴다. 전투 규칙과 출전/상점/장비 화면은 유지한다.

- 캐릭터 요약은 좌하단344×174 Canvas 단위다. 이전268×(Canvas 높이−244)의 세로 패널에서 줄였다. 기본1440×900 기준 면적이 약66% 감소한다. 기존 전신 Sprite와 이름/Lv, HP/MP/SP 막대, 이동·행동 여부, 능력 버튼만 표시한다.
- 전체 능력치·직업·상태는 능력 버튼의 상세창에서 확인한다. 상세창을 열면 배경 버튼과 전장 입력을 막고 닫기/Esc/우클릭/게임패드 B로 원래 선택 단계에 복귀한다.
- 행동 명령은 캐릭터 바깥쪽에 배치하고 화면 경계 안으로 제한한다. 긴 영문 병기 대신 짧은 한국어 명령을 표시한다. 기술 목록/설명은 오른쪽408폭 패널, 대상 선택의 실행/취소는 하단 오른쪽으로 모았다.
- 카메라 조작은 상단으로 이동했다. 전장 viewport는 왼쪽 전체 세로 패널 공간을 돌려받고 기술 목록이 열릴 때만 오른쪽 공간을 확보한다. 좁은 세로 창에서는 패널을 아래쪽으로 쌓는다.

실제 렌더링: [명령](command.png), [상세 정보](details.png), [기술](skills.png), [대상 선택](target.png).

전투 전체 UX를 교체한 것은 아니다. 전투 전/후 메뉴, 기술 선택→상세→대상 단계와 기존 피해 미리보기 문구는 유지한다. 원작 UI 에셋을 복제하지 않았으며 현재 남색·황동 테마를 사용한다. 최신 테스트/빌드/Windows 자동 진행 증거는 상위 VALIDATION.md를 따른다.
