성장 곡선: 아래 CSV는 1장 최초 → 2장 최초 → 2장 반복18회, 구매/매각/추가 드롭 없이 검증한 값이다. 장비를 얻어도 자동 매각하지 않는다. 레벨당 필요 EXP는 기존 Level×100, 상한50을 유지한다.


운영 기준:
- 시작300G에서 가죽 갑옷150G 구매 후 1장 최초 보상을 받으면270G다. 철검240G는 구매할 수 있고, 강화 갑옷300G는 2장 보상이나 추가 수입 이후 구매한다. 2장 확정 철검은 반복 플레이에서 매각 가능한 보상으로 유지했다.
- 상점의 기존 청동검100/가죽 갑옷150/부적100/철검240은 유지하고 강화 갑옷만280→300으로 조정했다. 기본 방어구와 상위 방어구의 가격 간격을 두 배로 맞췄다. 능력치·판매 해금은 변경하지 않는다.
- 초회 진행을 반복보다 유리하게 하되 두 장 완료 직후 Lv3을 보장한다. 이후 2장 반복18회까지 합계20회 클리어하면 Lv6/EXP420이다. 출전 캐릭터의 기존 EXP는 재산정하지 않는다.
- 반복 승리의 확정 장비 매각까지 고려하면 평균 총 가치는 1장133.75G/2장245G다(기본 골드+확정 장비 매각가+추가 장비 매각 기대값). 장비를 모두 팔고 상한에 닿지 않은 이론값이며 자동 지급 골드는 각각60/90G뿐이다.
- 저장 실패/예외 후에도 동일한 보상 객체로 재시도한다. 보유99개는 해당 장비만 미지급하며 재추첨하지 않는다. 출전 화면 복귀/앱 종료 시 미저장 보상은 포기된다. 전투 재개/미수령 보상 복구 저장은 이번 범위가 아니다.
- 이 표는 초기 경제 기준선이며 장시간 사람 플레이와 모든 파티 성장 조합의 최종 튜닝은 별도다. 표/곡선을 다시 생성하는 Editor 메뉴는 이 파일을 덮어쓰므로 수동 메모를 별도 보존한다.
