# 전투 아이콘 HUD

승인된 전투 UI 시안을 기존 uGUI 전투 흐름에 적용한다. 캐릭터/맵 콘텐츠, 전투 규칙, 비용, 저장 형식은 유지한다.

- 명령은 유닛 옆의 이동·공격·기술·대기 2×2 아이콘과 방어·이동 취소·출전 보조 버튼으로 구성한다.
- 기술은 한 페이지에 4장씩 표시한다. 이름/MP 비용, 사용 불가 표시, 선택 테두리를 제공한다. 다음/이전 페이지로 전체 기술과 궁극기에 접근한다.
- 선택한 기술의 사거리/속성/사용 조건만 기본 표시한다. 효과별 수치와 추가 조건은 기술 상세 창에서 확인한다. 상세 창을 닫아도 선택과 비용은 유지한다.
- 좌하단 캐릭터 정보는 초상·레벨·HP/MP/SP·행동 상태로 축소한다. 능력 버튼에서 전체 능력치를 확인한다.
- 상단에는 임무 진행, 다음 행동 유닛 초상, 작은 카메라/도움말/설정 버튼을 표시한다. 입력용 기존 버튼 이름과 콜백은 유지한다.
- 일반 명령 화면의 고정 로그 패널을 숨기고, 대상 선택/행동 연출/입문 연습에서 필요한 내용을 표시한다. 대상 선택 결과는 대상 가까이에 배치한다.
- 카메라는 배경을 화면 전체에 렌더링하고, 타일은 HUD 여백 안에 맞춘다. 시안에 있던 그림을 화면 전체에 덮는 방식이 아닌 실제 동작하는 게임 UI다.
- 아이콘은 해상도에 독립적인 uGUI 도형이다. 원화풍 개별 기술 일러스트를 새로 만든 것은 아니다.

검증 결과와 실행 파일은 상위 `VALIDATION.md`의 이번 변경 기록을 따른다. 배포된 `v0.1.0-preview.1`은 변경하지 않는다.
