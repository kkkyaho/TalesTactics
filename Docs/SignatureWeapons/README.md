# 전용무기 고유 이미지와 장착 외형

승인된10종의 아이콘과 전용무기를 든 캐릭터 외형을 적용한다. 장비 정비에서 무기를 선택하면 초안 외형을 미리 볼 수 있고, 장착·저장하면 편성·상태창·전투·이동 도착 미리보기에 반영한다. 해제하거나 일반 무기로 바꾸면 원래 외형으로 돌아간다. 획득 조건·수량·능력치·전용 효과·저장 형식은 그대로다.

| 캐릭터 | 무기 | 디자인 기준 |
|---|---|---|
| 크레스 | 이터널 소드 | 원작 아이콘 참고: 청은색 칼날, 금색 별 가드 |
| 민트 | BC 로드 | 원작 아이콘 참고: 은색 축, 작은 청색 수정 |
| 파라 | 갓 웨폰 | 더 레이즈 참고: 갈색 장갑, 은색 너클, 금색 커프 |
| 티아 | 유니콘 혼 | 승인된 신규 디자인: 나선 뿔, 은색 초승달, 보랏빛 보석 |
| 제이드 | 블러드 페인 | 승인된 신규 디자인: 암색 축, 진홍색 가시 창날 |
| 나탈리아 | 홀리 퀼카틀 | 승인된 신규 디자인: 상아색·금색 활, 깃털과 녹색 장식 |
| 벨벳 | 무명의 칼날 | 더 레이즈 참고: 은색·연녹색 직선 손목 칼날 |
| 알펜 | 네빌림 | 원작 장비 화면 참고: 붉은 칼날, 검은 가시 구조 |
| 시온 | 데모니시 코어 | 원작 장비 화면 참고: 검정·진홍 총몸, 은색 띠와 총구 |
| 키사라 | 오스 렉스 | 원작 장비 화면 참고: 검은 방패, 은색 뿔과 보라색 날개 |

원작에서 추출한 이미지가 아니라 승인 시안을 토대로 다시 그린 게임용 아트다. 특히 티아·제이드·나탈리아3종은 사용자가 허용한 신규 디자인이며 원작 외형과 동일하다고 주장하지 않는다. 다른7종도 원작 참조의 형태/색상을 반영한 재해석이다. 키사라의 반대 손 철퇴, 캐릭터 의상/체형, 기술의 별도 화염/속성 효과는 기존 구성을 유지한다.

## 에셋과 재현

- 원본 PNG52장: 캐릭터51장(1,404프레임) + 아이콘1장(10종). `Assets/TalesTactics/Art/SignatureWeapons`에 있다.
- `Tools/signature-art-generation.json`: 채택한 원본 경로, 참조 이미지, 전체 생성/교정 프롬프트. `proposal-sources.json`은 앞선 시안 단계의 자료/프롬프트를 그대로 보존한다.
- `approved-designs.png`: 승인된 열 무기 디자인 보드. 실제 게임 화면은 아래 엔진 캡처를 따른다.
- `MeasureSignatureArt.py`: Pillow/NumPy/SciPy로 alpha 영역을 읽고 원본 발 기준점·PPU를 보존하는 슬라이스/외곽선 CSV를 만든다. PNG 픽셀을 수정하지 않는다. 서로 겹치는 사각형 경계로 무기가 잘리지 않도록 연결 영역별 외곽선을 사용한다.
- `SignatureWeaponImporter.Import`: Unity Sprite Editor Data Provider를 통해 가져오며 기존 Sprite ID를 유지한다. 캐릭터 원본과 모션 클립, DemoContent를 재생성하지 않는다. `ValidateAll`은10종 아이콘/장착 외형과 실제 사용 프레임의 전체 연결을 검사한다.
- `alpha-audit.json`:51장/1,404프레임/이미지 가장자리 접촉0. 제이드의 일부 창이 옆 프레임과 닿던 첫 결과는 무기 길이를 교정한 뒤 채택했다. `art-sha256.json`은 최종 PNG의 해시다.

검수 실행은 별도 `SignatureWeaponReview`와 GUID 저장 폴더를 사용한다. 일반 게임 빌드에는 검수 타입이 들어가지 않는다.

## 검증 — 2026-10-14

- 실제 Unity6000.6.0f1 EditMode353/353(25.1028762초), 그래픽 Editor PlayMode144/144(371.1124691초). 사본은 `editmode.xml`, `playmode.xml`. 신규23개는 전체 프레임 연결, 잘못된 소유자/장비의 기본 외형 복귀, 저장 ID 유지, 장착 취소·저장 실패·재진입·해제, 모든 동작과4방향, 상태창·편성·이동 도착 미리보기를 검사한다.
- 별도 실제 Unity API 참조 Runtime/Editor/EditMode/PlayMode4개 컴파일 통과. ManagedChecks는 이번에 실행하지 않았다.
- 일반 Windows 빌드 오류0/경고1,45.012466초. 최종 검수 빌드 오류0/경고3,104.1929639초. `build-windows.txt`, `build-review.txt`에 최종 결과를 보존한다. 일반 DLL에 `SignatureWeaponReview`가 없고 `EquipmentAppearance`는 포함됨을 Mono.Cecil로 확인했다(`assembly-audit.json`).
- 실제 Windows 장비 화면10명×2해상도(1280×720·글자130%,1920×1080·100%)와 기본 외형10장, 편성1장, 전투2개 부대×4방향8장으로 총39장. 최종 텍스트 넘침/화면 밖 버튼/부대 누락/외형 미반영/수집 실행 오류0. [실제 화면 갤러리](gallery.html)에서 장착 전후를 비교한다. 전투는 열 캐릭터를 모두 확인하는 훈련 fixture이며 실제 획득/합류 조건을 변경하지 않는다.
- 최초 장비 검수에서 반복된 `장착 외형 미리보기` 설명의 높이 넘침20건을 발견하여 불필요한 설명을 제거했다(`player-review-initial.json`). 이 문구 수정은 전체 Unity 테스트 이후 Windows 재빌드와 실제 화면 검수로 확인했다. 최초 전투 캡처에서 합류 조건 때문에 두 명만 등장한 것도 발견해 훈련 fixture로 바꾸고 실제 부대 ID 전체 일치 검사를 추가했다. 최종 결과는 `player-review.json`이다.
- 일반 실행본 시작 유지와 실행 오류0, 사용자 저장/백업6개 해시 불변을 확인했다. 기존 사용자의 Unity Editor와 게임 프로세스는 유지했다. 기존 URP 피사계심도/Panini 셰이더 제거 경고가 남아 있으며 해당 후처리는 실행하지 않는다.
- 한계:1,404개 프레임의 연결·경계는 자동 검사하고 모든 시트와 대표 엔진 화면은 육안 검토했다. 사람이 전체 캠페인/모든 프레임을 하나씩 플레이하며 검수한 결과는 아니다.

일반 실행본: `Builds/SignatureWeaponsWindows/TalesTactics.exe`. 기본 게임에서 전용무기를 획득한 뒤 장비 관리에서 장착한다. 검수 fixture의 무기 지급과 레벨 설정은 일반 실행본에 들어가지 않는다.
