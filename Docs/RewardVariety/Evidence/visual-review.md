# 결과 보상 상세 화면 확인

실제 Editor PlayMode 표적3/3 검사에서 촬영한 1920×1080 원본3장을 확인했다. 7화 수련 지팡이(마력+8, 민트·티아), 14화 단련 갑옷(HP+70/방어+10, 합류 동료10명), 17화 집중 부적(이동-1/MP비용-15%, 합류 동료10명)의 그림·한글·수치·목록·화면 경계를 확인했다. 세 화면에서 추가 잘림이나 빈 아이콘을 발견하지 못했다.

선행 완료 플래그와 전투 목표는 검사 fixture이며 2인 시험 편성이다. 자연 성장 완주·전체14개 화면의 수동 확인·다른 화면 크기·Windows 화면 확인으로 확대하지 않는다. [원본 경로·SHA와 검사 범위](manifest.json).
