# 베이지색 방향 아이콘

승인된 두 번째 시안에 맞춰 대기 방향 표시를 수정했다. 짧고 두꺼운 몸통·넓은 화살촉·베이지색 윗면·얇은 갈색 측면으로 그린다. 선택 방향은 따뜻한 금색이다. 사각 버튼 배경·외곽선·별도 그림자는 없다.

22px 아이콘, 38×38 투명 클릭 영역, 머리 위 위치와 고저차/카메라 회전/글자 확대 대응을 유지한다. 측면 두께는 화면 아래쪽으로 일정하게 그려 카메라를 돌려도 광원 방향이 바뀌지 않는다. 기본 Unity UI 메시를 사용하므로 추가 이미지 리소스나 셰이더는 없다.

실행본은 `Builds/FacingIconsWindows/TalesTactics.exe`다. 기존 실행 중인 전투 표현 빌드와 구분되는 새 폴더이며 폴더 전체가 필요하다.

실제 그래픽 Editor PlayMode 관련 **4/4** 및 API 참조4개 컴파일 통과. Windows 일반/검수 빌드는 각각 오류0·기존 외부 패키지 경고3으로 성공했다. 일반 런타임 DLL의 검수 도구 제외를 확인했다. 기존 전체468개 검사를 이번에 재실행한 것은 아니다.

1280×720 Windows 검수 플레이어에서 방향4회전×글자2단계8장을 포함한 연출58장을 수집했고 런타임 수집 오류는0이다. 대표 실제 화면: [기본 글자](facing-1-0.png), [글자130%](facing-1.3-1.png). [검증 수치와 해시](validation.json), [Unity 테스트 원본](playmode.xml), [API 컴파일](api-compile.txt).

검수 플레이어는 별도 저장 경로에서 실행하며 화면 캡처는 연출 fixture다. 물리 입력 수동 완주를 뜻하지 않는다.
