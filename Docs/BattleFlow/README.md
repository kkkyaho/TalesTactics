# 전투 진행과 결과 화면

판매 준비 개선안 5번.

## 기술 선택 복귀

기술 목록 → 상세 → 목표 선택에서 취소하면 해당 기술 상세로 돌아온다. 상세에서 취소하면 목록으로 돌아오며 마지막 기술에 강조와 메뉴 포커스를 복원한다. 일반 공격의 취소는 행동 메뉴로 돌아온다. 기억은 캐릭터별이며 현재 실행 동안 유지한다. 목록을 다시 열어도 자동으로 기술을 실행하거나 MP를 소비하지 않는다.

## 적 행동 속도

**메뉴 F5 → 전투 진행**에서 적 행동 속도1·2·4배와 전체/간략 연출을 선택하고 저장한다. 다음 실행에도 유지한다. 속도는 적의 이동 보간·시전 준비·복귀 대기만 바꾼다. 간략 모드는 이동·기술 연출을 생략하고 실제 기술명/처리 결과를 하단 메시지에 남긴다. 적 AI·판정·비용·피해·상태·난수·턴 순서는 그대로다. 아군 연출과 파라 타이밍 판정 시간 및 전역 Time.timeScale은 바꾸지 않는다.

## 전투 결과

승리/패배·임무·저장 상태를 구분하고 실제 적용된 골드/장비 수량과 출전 캐릭터별 Lv/EXP 변화를 표시한다. 보유 상한 때문에 실제로 늘지 않은 수량은 획득으로 표시하지 않는다. 저장 실패 시 성장 결과를 표시하지 않고 같은 추첨으로 재시도한다. 보상 포기는 안내 버튼을 누른 뒤 확정한다.

저장된 승리에서는 전투 후 이야기·다음 장 출전 준비로 이어진다. 마지막 장에서는 다시 도전한다. 패배/훈련에는 보상이 없음을 표시하며 준비 화면 또는 재도전으로 돌아간다. 다음 장 버튼은 자동으로 전투를 시작하지 않는다.

최신 테스트·화면·Windows 검증 결과와 한계는 ../VALIDATION.md를 따른다.

## 검수 화면과 범위

- [적 행동 설정](settings.png): 실제 Game View 1366×768.
- [승리와 6인 성장](victory.png), [저장 실패](save-failed.png), [패배](defeat.png): 격리 저장에서 결과 상태를 구성해 배치와 문구를 확인했다. 이 캡처는 사람이 전투를 완주한 증거가 아니다.
- 패배 후 재도전이 이야기 없이 CommandState/Ongoing으로 시작함을 확인했다.
- PlayMode 검사는 실제 EnemyTurn의 동일 시드에서 비용·피해·상태·난수·다음 턴을 비교한다. enemy-speed.csv의 모드0/1/2/3은 1배/2배/4배/간략이며 단일 장면 측정값으로 전체 게임 성능 벤치마크가 아니다.
- Windows 캠페인 자동 검수는 1장1배·2장2배·3장4배·4/5장간략·6장1배로 실행한다. 별도 프로세스 저장/재개 검수도 사용자 저장과 분리한다.
- 실제 USB/Bluetooth 패드, 모든 화면 비율, 사람의 6장 완주·체감 속도 평가는 별도다.

최종 검증: Unity EditMode98/98·PlayMode67/67, Windows 일반/개발 빌드, 7회 캠페인 및 4회 SPD/CT 저장·재개 프로세스 모두 통과. 실행 파일은 Builds/WindowsBattleFlow/TalesTactics.exe. 세부 경고·초기 실패·실행 GUID는 ../VALIDATION.md의 개선안5 기록을 따른다.
