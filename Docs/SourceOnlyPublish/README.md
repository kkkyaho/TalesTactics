# 음원을 제외한 원격용 소스

2026-11-18 사용자는 로컬 음원과 현재 작업본을 보존하고, 사용자 제공 음원을 제외한 소스를 별도로 검증해 원격 develop에 반영하도록 승인했다.

이 소스는 로컬 develop `1cfabc77528b2ef37387fced7abc038da898e572`의 최신 게임 변경을 기준으로 한다. 공개 커밋의 부모는 기존 원격 develop `63f63ed23d0997a4b4bf51f14f3c0e05d4371bc6` 하나다. 음원을 포함한 미공개 로컬 6개 커밋을 조상으로 연결하지 않는다. 기존 원격의 과거 음원 이력은 남으며 이번 작업은 과거 이력을 지우거나 태그를 교체하는 작업이 아니다.

## 공개 구성

- `Assets/TalesTactics/Audio/LocalMusic/`의 MP3 6곡과 해당 meta, 폴더 meta를 최신 소스에서 제외한다.
- AudioLibrary에서 해당 6개 연결을 제거하고 기존 음악 14곡과 효과음 4개를 유지한다.
- 제품의 기존 대체 재생 기능을 사용한다. 타이틀·인터미션·일부 이야기는 story, 일반 전투는 battle, 보스 전투는 boss로 대체한다. 동료별 기존 테마는 유지한다.
- 사용자 음원 경로를 Git 제외 목록에 추가한다. 로컬 음악 가져오기 메뉴는 명시적으로 실행할 때만 작동하며 소스 음원을 다운로드하지 않는다.
- 검사는 음원이 전혀 없는 구성과 6곡이 완전히 연결된 구성을 구분한다. 부분 연결은 실패하며, 음원이 없는 구성도 실제 재생 검사를 건너뛰지 않는다.

## 검증 범위

별도 checkout을 새 Unity6000.6.0f1 프로젝트로 가져와 검증한다. 원본의 12개 수정 파일과 미추적 원화는 복사하지 않는다. 음원 관련 EditMode·PlayMode와 일반 Windows 빌드를 확인하며, 이전 전체 스테이지 검사 결과를 이 소스에서 새로 실행한 결과로 표현하지 않는다.

실제 EditMode **2/2**, PlayMode **9/9**(4개 묶음과 5개 별도 실행), 최종 일반 Windows 빌드 **51.16초·오류0·경고1**과 빌드 입력 파일 보존 검사가 통과했다. 경고는 Player의 Pipeline 런타임 설정이 없어 원격 제어가 비활성화된다는 안내다. 검수 코드 제외 검사도 통과했다. 최초 0개 실행·도구 오류·줄바꿈 변경으로 실패한 첫 빌드는 [실행 이력](Validation/execution-notes.md)에 보존했다. 6개 아이콘 meta는 빌드 후 줄 끝 공백만 원래대로 되돌렸으며 의미 값이 같음을 확인했다. [최종 빌드](Validation/build-final.json) · [입력 보존](Validation/build-source.json) · [음원 구성](Validation/audio-inventory.json). 일반 플레이어 실행, 사람의 청취 평가, 전체 음원의 끝까지 재생과 반복 경계 평가는 별도다.

## 이후 변경을 올릴 때

로컬 원본 develop은 음악 포함 이력을 보존하기 때문에 원격 develop과 이력이 다르다. 원본 develop을 그대로 푸시하거나 원격 공개 커밋에 merge하여 비공개 부모를 추가하지 않는다. 이후에도 최신 로컬 소스에서 음원 없는 스냅샷을 만들고, 당시 원격 develop을 단일 부모로 연결하여 검증한 커밋만 푸시한다. 원격 main과 태그는 이번 작업 대상이 아니다.
