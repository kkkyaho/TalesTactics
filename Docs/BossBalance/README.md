# 2장·6장 보스전 조정

새 자유 선택 턴 캠페인 전투에 호위 방벽을 적용한다. 살아 있는 같은 편 유닛 1명마다 보스가 받는 물리·마법·궁극기 피해가 25% 감소하며 최대 75%다. 거리·기절 여부와 무관한 생존 연결 방벽이다. 호위를 격파하면 즉시 감소하고, 부활하면 회복한다. 무적이나 강제 생존 턴은 없다. 피해 계산의 반올림과 최소 1 피해, 속성 면역 0 피해는 기존 규칙을 따른다.

2장 보스를 후방 (6,9), 6장 보스를 (6,12)에 두고 호위 위치를 벌렸다. 2장 골렘 보스도 공격 예고 → 고정 위치 발동 → 빈틈 주기를 사용한다. 공격 직전 방벽은 임무 진행·대상 예측, 호위 처치 후 변화는 전체 예측에서 확인할 수 있다. 범위 공격은 기존 대상/효과 처리 순서대로 계산하며 미리보기도 복제 전투에서 동일하게 실행한다.

중단 저장 V5에 BossEncounters를 추가했다. V1–V4 기록은 기존 방벽 없는 규칙과 저장 위치로 복원한다. SPD/CT, 훈련, 다른 장에는 적용하지 않는다. 캠페인 외부 저장 버전은 2다. 새 V5 중단 기록은 이전 실행본에서 읽을 수 없으므로 되돌리려면 이전 백업이 필요하다.

## 자동 전투 비교

`Tools/ReviewBossBalance.ps1`은 시작 권장 레벨, 장별 숙련 및 6장 궁극기 체험, 장비·성장 방향 보정 없는 6인으로 같은 AI를 양 팀에 적용한다. turns는 유닛별 행동 횟수이며 페이즈 수가 아니다.

| 편성 | 2장 기존 → 조정 행동 수 | 6장 기존 → 조정 행동 수 | 조정 후 보스 자기 턴 (2장/6장) |
|---|---:|---:|---:|
| 추천 | 5 → 12 | 2 → 12 | 1 / 1 |
| 공격형 | 6 → 9 | 4 → 16 | 1 / 2 |
| 지원형 | 6 → 11 | 3 → 10 | 1 / 1 |

12경우 모두 승리·아군 6명 생존. 기존 6경우는 첫 아군 페이즈에 보스가 쓰러졌고 조정 후 6경우는 모두 적군 페이즈를 거쳤다. 보스가 반드시 예고 공격을 끝내도록 강제하지 않는다. 이 결과는 인간 플레이의 난이도 균형, 모든 행동 순서·장비·레벨에서 선제 격파 불가능함을 증명하지 않는다. 사람이 여러 편성으로 6장까지 완주하는 검수는 남아 있다.

## 현재 검증

Unity 6000.6.0f1 EditMode 149/149(0.72초), PlayMode 전체 101/101(196.83초) 통과. 새 검사는 물리/마법 방벽 감소, 호위 격파 및 궁극기 범위 예측/실행 일치, 저장 버전/배치 복원, 훈련·SPD·CT·다른 장 제외, 실제 임무 UI를 포함한다. Runtime/Editor/Tests/PlayModeTests API 참조 컴파일도 통과했다. `editmode.json`, `playmode.json`에 실제 엔진 결과를 기록했다.

임무(2장/6장)·전체 예측을 5해상도(1024×768,1280×800,1366×768,1920×1080,2560×1080)×글자100/130% **30조합**으로 검사하여 문구 넘침/화면 밖 버튼 0을 확인했다. `aspect-matrix.json`과 PNG는 격리된 임시 저장을 사용한 Editor Game View 증거다. 예측 화면은 검사자가 유닛 위치를 직접 설정한 표시 검사이며 수동 이동 시나리오를 의미하지 않는다. 1024×768 글자130% 임무/예측 및 Full HD 6장 임무 PNG를 직접 확인했다.

마지막으로 보스의 예고/빈틈 정보를 방벽 일반 설명보다 먼저 표시하도록 우선순위를 보완했다. 같은 화면의 평상시 문구는 동일하며, 최종 EditMode149/149(0.76초)와 해당 PlayMode1/1(1.57초)을 다시 통과했다(`mission-regression.json`).

Windows 일반 빌드 `Builds/WindowsBossBalance/TalesTactics.exe` 성공(25.154초,오류0/기존 경고10). 실행에는 폴더 전체가 필요하다. 숨김 실행12초 유지·로그 오류0, 사용자 캠페인/설정 계열3파일 SHA256 불변. `windows-build.json`, `windows-startup.json`, `user-save-check.json` 참조. 공개 Release 배포는 이번 범위에 포함하지 않았다.
