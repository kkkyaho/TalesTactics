# 전투 표현 개선 적용

사용자가 승인한 1·2·3·4번을 적용했다. 5번 초상화 대화는 개발안 상태다. 실행 파일은 `Builds/CombatPresentationWindows/TalesTactics.exe`이며 폴더 전체가 필요하다.

## 피해와 경험치

- 피해 숫자는 월드 TMP와 검은 사각형을 제거하고 화면 Canvas의26px 숫자로 표시한다. 회복은 청록, HP 소비는18px 보조 표시이며 0.85초에 걸쳐 짧게 올라간다. 카메라 거리로 크기가 변하지 않는다. 해당 유닛의 상세 HP 글자는 잠시 숨겨 숫자와 겹치지 않게 하고 HP 막대는 유지한다.
- 경험치는340×98 패널의 초상화·이름·레벨·5px 게이지로 표시한다. ActionExperience.Grant가 전후 EXP/레벨을 기록하며 큐는 그 스냅샷으로 재생한다. 레벨업은100을 채운 뒤 잔여 EXP를 이어 표시한다. 최대 레벨은 MAX다.
- 정보 패널은 클릭을 가로채지 않으며 기술/대상 명령창 위쪽으로 자리를 옮긴다. 모달·이야기 중에는 감추고, 중단·재도전·되감기·새 전장에서 대기 표시를 초기화한다.

## 머리 위 방향

- 지면 방향 메시를 제거했다. 캐릭터 스프라이트의 실제 머리 상단을 화면에 투영하고22px 화살표4개를 배치한다. 클릭 영역은38×38, 선택 방향은 금색이다.
- 카메라 회전에 따라 월드 방향을 재투영하며 글자 확대 설정을 반영한다. 화면 가장자리에서는 범위를 보정한다. 방향 선택 중 상세 HP 텍스트를 감춰 머리 위 표시 공간을 확보한다.
- 원래 포인터 미리보기·클릭 확정·방향키·Enter·Esc와 패드 Submit 경로를 유지한다. 방향 선택은 전투 유닛을 미리 회전시키거나 움직이지 않는다.

## 속성과 물리 모션

- 실제 투명 화염12프레임·연기4프레임 아틀라스를 런타임 UV 애니메이션으로 사용한다. 불꽃 중심·겹친 화염·잔불·연기를 분리한다. [내장 image_gen 생성 기록과 프롬프트](image-generation.json).
- 얼음은 결정 파편, 대지는 파편/먼지, 번개는 분기된 방전, 물은 물방울/회전 흐름, 바람은 회전 띠, 빛은 방사 광선, 어둠은 어두운 중심과 회전 띠로 표현한다. 회복/지원은 상승 입자와 얇은 파동이다.
- 검/불꽃검/클로의 넓은 궤적, 격투/방패의 접촉 파동, 창·활·총의 방향성 궤적을 실제 캐릭터·스킬 속성에 따라 연결한다. 기존 개별 스킬 패턴도 함께 유지한다.
- 물리 모션은 기존 방향별 원화를 재사용하고 전진·준비 반동·몸통 기울기·접촉 정지·피격 반동을 강화한다. 물리 공격/스킬의 최소 회복 연출은0.55초다. 위치/피해/경험치 판정과 전역 timeScale은 변경하지 않는다.
- 전장 단위로 최대16개의 효과 인스턴스를 재사용한다. 메시와 재질은 전장 종료 시 해제한다. 전투 난수는 소비하지 않는다. 설정의 ‘효과: 부드럽게’는 입자 수와 섬광을 줄이며 기존 설정 파일에서는 풍부하게가 기본이다.

## 기존6장

기존6장 목록·출전·대사·중단 이어하기 제거를 유지한다. 저장된 성장·장비·골드·완료 이력과 호환용 장 번호는 보존한다. 새 메인20화·개인30단계를 진행한다.

## 검증 범위

- 실제 Unity EditMode **333/333**, 보정 후 그래픽 Editor PlayMode **135/135** 통과. [EditMode 원본](editmode.xml), [PlayMode 원본](playmode.xml), [빌드·해시·화면 검증 기록](validation.json).
- Windows 일반/검수용 빌드 성공, 각각 오류0·기존 외부 패키지 경고3. 일반 런타임 DLL에는 `CombatPresentationReview`가 포함되지 않는다.
- 격리된 Windows 플레이어 1280×720 엔진 캡처58장: 방향8·피해/EXP2·속성18·영웅10명 공격3단계30. 런타임 수집 오류0. [결과](result.json), [실제 기술별 속성/무기/패턴 연결](skill-mapping.csv).
- 중간 배치 모드 재검사는110/135·25실패였다. `WaitForEndOfFrame` 미지원15건과 상태/배치 검증 실패가 있었으며, 이를 대신해 최종 그래픽 Editor 전체 실행135/135를 확인했다.
