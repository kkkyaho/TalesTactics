# 6장 픽셀 아트 개편

승인 시안의 캐릭터 특징과 3등신 비율을 기준으로 기존 10명을 고밀도 픽셀 일러스트로 교체했다. 장비의 금속 반사, 의상 문양, 머리카락과 망토의 명암을 보강했다. 원작 프레임 복제가 아닌 프로젝트용 재해석이다.

- 영웅: 크레스·민트·벨벳·파라·티아·제이드·나탈리아·알펜·시온·키사라. 각 기본/이동/보충 시트 3장, 4방향 48개 그림. 시온의 오른쪽 동작은 별도 4개 그림으로 보정했다.
- 적: 울프·슬라임·록 골렘·유적 파수병·궁수·마법사·오타오타·에그베어·펭기니스트와 최종 보스 다오스. 일반 적은 각 20개, 다오스는 32개 그림이다.
- 전장: 16종 재질, 16종 장식과 6장별 원경. 실제 이동 타일/높이/장애물/스폰은 유지하고 장식에는 충돌체를 두지 않는다. 장식과 원경은 카메라 회전에 맞춰 표시한다.
- UI: 기존 메뉴 배치에 짙은 남색과 황동 테두리를 적용했다.

영웅 보행은 서로 다른 4프레임, 기술은 시전/공격 그림 2개, 궁극기는 전용 준비/발동 2개를 사용한다. 쓰러짐은 피격→쓰러짐→마지막 그림 유지의 3프레임 클립이다. 각 일반 기술마다 별도의 전신 작화를 제공하지 않으며 기존 기술별 VFX와 전투 판정은 유지한다. 일반 적은 보행 두 걸음과 대기 그림을 조합하며 일부 상태에 기본 그림을 공유한다.

## 편성

| 장 | 적 편성 |
|---|---|
| 1 유적 외곽 | 오타오타·울프·슬라임·파수병 |
| 2 심층 제단 | 골렘·파수병·마법사·슬라임 |
| 3 협곡 | 에그베어·울프·궁수·파수병 |
| 4 관측소 | 마법사·골렘·궁수·파수병 |
| 5 수문 | 펭기니스트·오타오타·에그베어·궁수 |
| 6 중계핵 | 다오스·골렘·마법사·파수병 |

다오스는 기본 AI에서도 UtilityPlanner로 레이저와 범위 블래스트를 선택한다. 전멸 승리 조건을 유지하므로 호위도 격파해야 한다. 원작 대사를 복사하지 않은 창작 전후 이야기로 6장까지 연결했다. 기존 캐릭터 능력치/기술/장비/성장 및 V2 저장과 장별 보상은 유지했다.

## 제작·편집

모든 신규 PNG는 내장 imagegen으로 제작했다. 승인 시안은 이 폴더의 approved-heroes-maps.png와 approved-monsters.png다. 최종 채택 원본 및 프롬프트는 Tools/pixel-final-generation.json에 기록했다. 해당 기록의 원본 경로는 제작 이력이며 게임은 Assets 아래 복사본만 사용한다.

Tools/MeasurePixelCampaign.py는 alpha를 읽어 경계·발 기준점·여러 윤곽을 CSV로 기록하며 원본 픽셀을 변경하지 않는다. PixelArtImporter는 Sprite Editor API로 가져오기 및 CharacterData 참조를 적용한다. Point/무압축/밉맵 없음으로 가져오며 각 시트의 서 있는 그림 크기로 PPU를 정규화한다. 3D 회전 카메라이므로 모든 확대 배율에서 정수 픽셀 배율을 보장하는 렌더러는 아니다.

PixelCampaignContent.CreateEnemies는 새 적 에셋이 없을 때만 초기 수치를 만든다. 기존 에셋 수치를 덮어쓰지 않는다. 아트 가져오기는 명시적 교체 작업이며 사용자가 Sprite 참조를 바꾼 뒤 자동 재실행하지 않는다. DemoContent.Create를 재실행하지 않았다.

검증 결과와 캡처 범위는 ../VALIDATION.md의 최신 픽셀 개편 기록을 따른다. 이전 ART_ACCEPTANCE.md의 2026-09-27 기록은 이전 그림에 대한 이력이다.
