# 3번 — 전투 운영 규칙

출전 준비 → 전투 규칙 설정에서 선택한다. 기본은 기존 SPD 라운드/기본 AI이며 CT와 Utility를 각각 켜서 캠페인 또는 훈련에 적용할 수 있다. 설정은 이번 앱 실행 동안 유지하고 저장 형식은 변경하지 않는다.

## CT

CTTurnScheduler는 살아 있는 유닛의 SPD만큼 정수 틱마다 CT를 쌓고 1000 이상인 유닛을 행동시킨다. 가장 많이 쌓인 유닛을 우선하며 동률은 배치 순서다. 행동당 1000을 차감하고 잔여값을 보존하므로 빠른 유닛이 더 자주 행동한다. SPD는 매 계산 시 다시 읽고 0 이하를 1로 처리한다. 관측된 KO/명단 제외 유닛의 CT는 삭제된다. 부활 시 새로 참여한다.

미리보기는 CT 복사본에서 다음 8회를 계산한다. 실제 순서나 자원을 변경하지 않으며 미래의 스킬·상태 변화까지 예측하지는 않는다. 행동 종류별 Delay/대기 보너스는 이번 구현 범위에 포함하지 않는다.

## Utility AI

도달 가능한 위치와 사용 가능한 기본 공격/스킬/궁극기/전술 스킬의 목표 타일을 비교한다. SkillResolver의 비용·해금·게이트·시야·범위·속성·고저차를 그대로 사용한다. 유효 피해, 처치, 실제 부족 HP 회복, 부활, 상태 해제/부여를 평가하고 MP/HP/게이지 비용과 노출 위험을 감점한다. 남는 유효 행동이 없으면 접근하거나 가드한다. 같은 입력의 결과는 결정적이다.

후보 평가 중 임시 위치·점유·방향은 finally에서 복원하고 자원을 소비하지 않는다. 적은 Utility 모드에서 기존 응급 회복(mint.0)과 땅 마법(jade.0)을 전투별 추가 기술로 사용한다. 원본 CharacterData/SkillData 에셋은 변경하지 않는다.

단일 행동 비교 방식이다. 다중 턴 탐색·Flaming Edge 추가 연계·파라 타이밍 연계·상태 확률의 장기 최적화는 하지 않는다. 기본 AI도 계속 선택할 수 있다.

## 목표

특수 목표 버튼은 훈련 모드로 전환한다. 캠페인은 기존 전멸 목표를 유지하며 훈련에는 모든 저장 보상이 없다.

|목표|승리|패배|
|---|---|---|
|모든 적 격파|살아 있는 적 없음|아군 전멸|
|보스 격파|첫 적 격파(기존 레벨+5, 최대50)|아군 전멸|
|목표 도착|살아 있는 아군 1명이 금색 (8,8) 타일 도착|아군 전멸|
|호위|첫 출전 캐릭터가 살아서 (8,8) 도착|호위 대상 KO 또는 아군 전멸|
|생존|살아 있는 아군의 턴 종료 총12회|아군 전멸|

보스/호위 대상은 금색 HP 막대로 표시한다. 호위 캐릭터는 플레이어가 직접 조작하는 출전 인원이며 별도 자동 이동 NPC가 아니다. 도착/호위/생존에서는 적 전멸만으로 승리하지 않는다. 동시에 승패 조건을 충족하면 패배가 우선이다. 자동 부활 후 살아 있다면 KO 패배로 보지 않는다.

생존의 12회는 라운드나 개인별 12턴이 아닌 파티 전체의 턴 종료 합계다. 기절로 건너뛴 아군 턴도 종료 시 집계된다. 같은 턴 종료를 중복 호출해도 1회만 집계한다. 도착 승리는 이동 애니메이션 후 결과 화면으로 연결한다.

## 검증

실제 Unity 결과는 VALIDATION.md와 unity-*-tactical-systems.json을 따른다. tactical-scenarios.csv는 6인 Lv25/적 Lv10, CT+Utility로 강제 피해 없이 다섯 목표를 완주한 실행 기록이다. 이는 목표 연결 검증이며 동레벨 난이도 균형을 증명하지 않는다.

Windows 캠페인 회귀: `./Tools/RunCampaignReview.ps1`
CT+Utility Windows 캠페인 검수: `./Tools/RunCampaignReview.ps1 -Tactical`
두 경우 모두 새 GUID 슬롯에서 수행하며 사용자 저장/백업 해시를 비교한다.
