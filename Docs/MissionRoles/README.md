# 임무 정보와 적 역할

판매 준비 개선안 6번. 캠페인 6장의 기존 전멸 목표·보상·저장 스키마를 유지한다.

출전 준비의 **임무 · 적 정보**, 전투 상단의 같은 버튼에서 승리/패배 조건, 진행 상태, 장별 접근 방법과 적 네 명의 역할·기본 기술/사거리·대응법을 확인한다. 전투 중에는 현재 HP와 격파 여부를 표시한다. 이 정보는 예정 행동의 확정 예고가 아니며, 실제 공격 가능 여부는 높이·시야·상태에 따라 달라진다.

| 역할 | 대상 | 행동과 대응 |
|---|---|---|
| 전열 | 슬라임·센티널·골렘·에그베어 | 기존 근접 압박. 전방에서 받아내고 측후면 공략 |
| 돌격 | 울프·폴위글·펭기니스트 | 공격 가능한 부상자를 더 우선시. 후방 보호·회복 |
| 사격 | 궁수 | 유효 사거리 안에서 적과 거리를 유지. 엄폐·근접 압박 |
| 마법 | 마법사 | 유효 사거리 안에서 거리 유지. 마법 방어·근접 압박 |
| 보스 | 다오스 | 기존 Utility의 직선/범위 선택. 밀집 회피, 부하까지 격파 |

거리/대상 보정은 캠페인의 적에게만 적용하고 기본 AI와 Utility AI가 공유한다. 훈련 적·아군 자동 검수 판단은 기존 규칙을 사용한다. 새 기술이나 수치/에셋 재생성은 하지 않는다. 적 역할 차이는 기존 능력치·공격 특성과 이번 이동/대상 선호의 조합이며 모든 적에게 별도 AI 상태 머신을 추가한 것은 아니다.

시스템·도움말과 임무창은 단독으로 열리며 배경 버튼/타일/대상 순환을 차단한다. 닫기·Esc·우클릭·패드 B로 돌아가고 Restart에서도 닫힌다. 정확한 검사 수·Windows 실행·시각 검수의 범위는 ../VALIDATION.md를 따른다.
