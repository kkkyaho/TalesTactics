# 0.1.0-preview.9 변경 안내

Preview8 이후의 SD 미술, 전장 입체감, 전투 HUD와 동료 합류·음악 개선을 담은 Windows 공개 테스트 버전입니다. 게임 범위는 메인 20화와 동료 개인 이야기 30단계를 유지합니다.

## 변경 사항

- **SD 미술과 캐릭터 원화:** 캐릭터·적·보스·전용무기와 초상화, 메뉴·아이콘·전장을 SD 스타일로 통일했습니다. 기존 스프라이트 식별자와 장비 외형 연결을 보존하고, 후속 작업에서 동작별 원화와 크기를 보완했습니다.
- **모션과 기술 연출:** 기존 기술의 준비·타격·회수 흐름, 검격·접촉 강조와 주문의 뒤쪽 표현을 개선했습니다. 전투 판정과 기술 수치는 유지합니다.
- **자연스러운 전장:** 바닥 문양의 반복, 타일마다 끊기던 물결, 직선으로 이어진 외곽을 줄였습니다. 풍화된 판석·이끼·바위 단면과 수면 흐름을 보완하며 실제 이동 격자와 지형 높이는 유지합니다.
- **캐릭터의 입체감:** 발 접촉 그림자에 몸·무기 실루엣 그림자를 더하고 환경광을 맞췄습니다. 뒤쪽 벽에 몸통이 잘리는 문제와 단차가 있는 투명 기둥의 앞뒤 정렬을 수정했습니다. 앞쪽 장애물은 계속 캐릭터를 가립니다.
- **전투 HUD:** 명령창은 선택한 캐릭터 옆에, 상태창은 좌측 하단에 배치했습니다. 작은 HP바와 발밑 방향 선택으로 전장 정보를 정리하고, 긴 목표·전술 도움말은 임무 메뉴에서 확인하도록 했습니다. 기존 카메라 이동·회전·확대와 단축키는 유지합니다.
- **대기 동작과 크기:** 캐릭터별 호흡·체중 이동·팔과 무기의 흔들림, 미세한 시선·눈매 변화를 추가했습니다. 행동·피격·사망 중에는 기존 포즈를 사용합니다. 알펜은 투명 여백을 제외한 실제 몸체 높이를 기준으로 크기를 맞췄습니다.
- **합류·성장·상점:** 동료는 실제 첫 등장 전까지 거점 목록에 나타나지 않으며, 첫 등장 전투에 출전합니다. 새 동료의 합류 레벨은 이미 합류한 동료 전체의 평균을 내림해 처음 한 번 적용합니다. 기존 성장치는 보존합니다. 새 캠페인에서 일반 장비가 계속 잠기던 문제와 합류 훈련 저장 실패 처리를 수정하고 일반 무기 7종을 추가했습니다.
- **상황별 음악:** 지정 음악 6곡을 타이틀·거점·일반전·주요 보스전·결전에 연결했습니다. 기존 음악 14곡과 효과음은 유지합니다. 같은 거점 메뉴를 다시 열어도 곡을 재시작하지 않으며, 비오의 종료 후 이전 곡의 재생 위치를 복원합니다.

## 업데이트와 저장

실행용 Windows ZIP을 **새 폴더에 전부 압축 해제**하고 `TalesTactics.exe`를 실행하세요. Source code ZIP은 실행용이 아닙니다. 업데이트 전에는 게임을 종료하고 기존 저장을 백업하세요.

캠페인 V1~V3 읽기/V3 쓰기, 설정 V1, 중단 전투 V11을 유지합니다. 기존 완료 기록·더 높은 레벨·EXP·승급·장비·특성·해금 기술을 보존하며, 이미 합류한 동료의 성장치를 다시 계산하지 않습니다. 이전 중단 전투의 합류 상태도 준비 화면에서 저장할 때 보존합니다. **구6장 중단 전투는 이어갈 수 없다는 기존 제한은 유지**합니다. 구버전으로 돌아갈 때는 업데이트 전 저장 백업을 사용하세요. 사용자 저장·로그·개인 음악 대체 파일은 배포 대상이 아닙니다.

## 검증 범위와 한계

기능 개발 단계의 실제 Unity 전체 EditMode는 **469/469 통과**했습니다. 전체 PlayMode는 **281/282 통과** 후, 유일하게 실패한 기존 상점 검사의 합류 전제를 보정하여 **별도 1/1 통과**했습니다. 단일 전체 282/282 실행 결과는 아닙니다. 뒤·앞 장애물과 단차 정렬, 대기 표현의 GPU 표적 검사도 통과했습니다.

개발 검수용 Windows 실행본에서 전장 **90/90**, HUD **32/32**, 음악 **14/14구간**, 자동 캠페인 **20/20화**를 확인했습니다. 캠페인은 실제 전투·대화·보상과 저장 재로드를 거쳤으며, 각 검수 실행은 정상 종료했고 사용자 저장 트리의 파일·디렉터리를 보존했습니다. 기능 개발 검증과 배포 패키지 검사는 구분합니다. [기능 검증 원문과 실제 화면](https://github.com/kkkyaho/TalesTactics/blob/e081a592d398aa0354b04a827fb3833a277552d2/Docs/PlaytestFeedback/README.md)

전장·HUD·얼굴의 육안 검수는 표본이며 모든 이미지의 승인은 아닙니다. 그림자는 2.5D 투영이며 완전한 입체 그림자가 아니고, 얼굴 표현도 새 리깅이나 완전한 눈 감기가 아닙니다. 음악은 짧은 재생·전환 관측으로, 전곡 청취·루프 연결부·음질 또는 곡별 PCM 분리 검증은 하지 않았습니다. 자동 캠페인은 배속과 정해진 합법 명령을 사용하므로 사람의 자연 진행 시간·밸런스 평가와 다릅니다. 다른 PC/DPI·물리 입력 장치·전체 캠페인 수동 완주·장시간 성능은 추가 검수 대상입니다.
