TalesTactics — Windows x64 테스트 배포

시작
1. ZIP을 버전별 새 폴더에 모두 풉니다. ZIP 안에서 실행하지 마세요.
2. TalesTactics.exe를 실행합니다. Data/DLL/MonoBleedingEdge 폴더도 필요합니다.
3. 처음 플레이 · 도움말에서 입문 연습을 시작할 수 있습니다.
4. 마우스로 전장 타일 선택, 메뉴 Tab/Shift+Tab 이동, Enter 선택, Esc 취소.
   F1 도움말, F5 저장·설정, Q/E 카메라 회전, Home 카메라 초기화.
   M 이동 / A 공격 / S 기술 / G 방어 / W 대기 / Z 이동 취소 / V 위험 표시.
   대상 위에 커서를 올려 예측을 확인하고 클릭하면 즉시 사용합니다.
   방향키로 전장 타일을 선택하고 Enter로 확정할 수도 있습니다.

업데이트 (전체 패키지 교체 방식)
1. 실행 중인 게임을 모두 종료합니다.
2. 아래 백업 도구로 저장/설정을 백업하고 출력 폴더를 보관합니다.
3. 새 ZIP의 SHA256을 제공된 체크섬과 비교합니다.
4. 기존 게임 폴더 위에 덮어쓰지 않고 새 버전 폴더에 풉니다.
5. 무결성 검사 후 새 폴더의 TalesTactics.exe를 실행합니다.
6. 저장 슬롯과 중단 전투 이어하기를 확인한 뒤 이전 폴더 정리를 결정합니다.
   사용자 저장은 게임 폴더 밖에 있으므로 새 폴더에서도 자동으로 읽힙니다.

Windows PowerShell에서 실행 (패키지 폴더에서)
  powershell -NoProfile -File .\Verify-Package.ps1
  powershell -NoProfile -File .\Backup-Saves.ps1
정책 때문에 실행할 수 없다면 내용을 확인한 로컬 스크립트에 한해
powershell 명령에 -ExecutionPolicy Bypass를 추가할 수 있습니다.
이는 해당 프로세스에만 적용되며 시스템 정책을 영구 변경하지 않습니다.
직접 실행하지 않으려면 아래 저장 위치의 파일을 별도 폴더에 복사합니다.
체크섬 비교: Get-FileHash .\TalesTactics-버전-windows-x64.zip -Algorithm SHA256
SHA256은 다운로드 손상 확인용이며 게시자 서명을 대신하지 않습니다.

저장 위치
  %USERPROFILE%\AppData\LocalLow\LocalTactics\TalesTactics
  campaign.json / campaign-slot2.json / campaign-slot3.json / settings.json
  같은 이름의 .bak / .v1.bak / .corrupt-*도 함께 보관합니다.
기본 백업 위치: Windows 문서 폴더\TalesTacticsBackups\날짜-GUID
백업 폴더의 manifest.json은 파일 목록과 SHA256입니다.
  powershell -NoProfile -File .\Verify-Package.ps1 -Directory "백업 폴더 전체 경로"
백업 도구는 원본을 읽어 복사하며 원본 삭제/수정/자동 복원은 하지 않습니다.
저장 파일이 아직 없으면 백업할 파일이 없다고 종료합니다.

문제 발생 / 이전 버전으로 복귀
1. 게임을 종료하고 현재 저장 폴더도 별도로 복사해 보관합니다.
2. 이전 게임 폴더를 실행합니다. 최신 저장을 이전 게임이 읽는다는 보장은 없습니다.
3. 호환되지 않으면 업데이트 전 백업의 무결성을 검사합니다.
4. 위 저장 위치의 대상 파일을 현재 보관본으로 옮긴 뒤 업데이트 전 백업 파일을
   원래 이름으로 복사합니다. 백업에 없던 새 슬롯은 섞지 않습니다.
5. 이 복원은 백업 이후 진행 상황을 되돌립니다. 보관본을 삭제하지 마세요.
현재 저장은 V1 읽기/이관, V2 읽기/쓰기, 설정 V1입니다.
미지원 최신 저장은 보호되지만 구버전 실행과 세이브 호환성을 뜻하지 않습니다.
앱 폴더만 교체하는 업데이트에서 저장 형식을 자동으로 낮추지 않습니다.

문제 제보에 포함할 정보
manifest.json의 version/sourceCommit, Windows 버전, 해상도, 입력 장치,
재현 순서, 기대 결과/실제 결과를 기록합니다.
로그: 저장 위치의 Player.log (다시 실행하기 전에 별도 복사).
저장·로그에는 플레이 기록과 로컬 경로가 있을 수 있으므로 직접 확인한 뒤 제공합니다.
이 패키지는 로그나 저장을 원격으로 자동 전송하지 않습니다.

범위
6장 테스트 배포입니다. Windows x64 현재 개발 PC에서 검증했습니다.
별도 최소 사양 PC, 물리 게임패드, DPI/전체화면 전환 검수는 남아 있습니다.
자동 온라인 업데이트, 설치 프로그램, 코드 서명, 스토어 등록은 포함하지 않습니다.
폰트 고지는 TalesTactics_Data/StreamingAssets/Licenses에 포함되어 있습니다.
