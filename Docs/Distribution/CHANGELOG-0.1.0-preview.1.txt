0.1.0-preview.1 — 2026-10-07

첫 버전별 Windows x64 로컬 배포 패키지.
배포 번호는 manifest.json에 기록됩니다. 게임 실행 파일의 제품 버전은 0.1.0입니다.
검증된 WindowsAccessibility 빌드를 포장하며 전투 코드/콘텐츠 변경은 없습니다.

포함된 최근 개선
- 울트라와이드 준비 화면 편성/상점과 하단 영역의 겹침 수정.
- 메뉴 Tab/Shift+Tab 순환, 금색 선택 표시 및 키보드/패드 입력 전환.
- 전투 숫자와 긴 기술명 대비 보강, 효과음 동시 재생/중복 완화.
- 6장 캠페인, 저장 3슬롯, 중단 전투, 도움말/입문 연습.

배포 도구
- 전체 파일 SHA256 manifest, ZIP 체크섬, 설치 폴더 무결성 검사.
- 게임 종료 후 저장/설정과 기존 백업 파일을 별도 폴더로 복사.
- 새 폴더 업데이트와 업데이트 전 저장으로 복귀하는 절차.

확인된 한계
- 사람의 2~6장 난이도/경제 평가와 최종 작화/실기기 청음은 미완료.
- 실물 USB/Bluetooth 패드, DPI/전체화면 및 별도 PC 검수는 미완료.
- 키 재설정, 키보드만의 전장 타일 조작, 글자 배율/색각 옵션 미제공.
- 자동 패치 다운로드/스토어 업로드/설치 프로그램/코드 서명 미제공.
