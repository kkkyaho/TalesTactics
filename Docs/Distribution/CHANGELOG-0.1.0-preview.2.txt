TalesTactics 0.1.0-preview.2 — Windows x64

시스템·UI 개선 테스트 배포
- 대상 클릭 즉시 기술 사용, 캐릭터 옆 명령·기술·예측창.
- 적 위험 범위와 고정 공격 예고, HP·회복·자원·상태 결과 예측.
- 역할별 적 AI, 보호·예고 공격·휴식 중 빈틈.
- 6장에 전멸·보스 격파·도착·생존·호위 목표 적용.
- 선택 특성 5종, 장신구 3개, 추천 6인 편성·합류 훈련.
- 캠페인 진행에 따른 일반 기술 해금과 6장 궁극기 체험.
- 키보드 전장 조작과 글자 최대 크기 100/115/130%.
- 개인 PC의 PersonalMusic 폴더에서 선택적으로 BGM을 불러옵니다.
  개인 음원은 이 배포에 포함하지 않으며 기본 오리지널 음악을 제공합니다.

주요 조작
M 이동 / A 공격 / S 기술 / G 방어 / W 대기 / Z 이동 취소 / V 위험 범위
방향키 타일·방향 선택 / Enter 확정 / Tab 대상·메뉴 전환 / Esc 취소
유효한 대상 클릭은 즉시 사용합니다. 커서를 올리면 미리보기만 표시합니다.
F1 도움말 / F5 저장·설정 / Q·E 카메라 회전

업데이트와 저장
- 기존 게임 폴더를 덮어쓰지 말고 새 폴더에 전체 압축을 풉니다.
- 업데이트 전 포함된 Backup-Saves.ps1 또는 수동 복사로 저장을 백업하세요.
- 저장 V1 읽기/이관, V2 읽기/쓰기와 기존 편성을 유지합니다.
- 이전 전투 중단 기록은 기존 전멸 목표로 이어집니다.
- 새 전투 중단 기록에는 장별 목표 진행과 공격 예고를 저장합니다.
- 새 중단 기록은 이전 실행 파일과 호환되지 않을 수 있습니다.
  이전 버전으로 복귀할 때는 업데이트 전 저장 백업을 사용하세요.

확인한 범위
- 실제 Unity EditMode 125/125, PlayMode 87/87 통과.
- Windows 일반/개발 빌드, 6개 장 자동 진행과 재실행·저장·보상 확인.
- Editor Game View 5개 해상도에서 기술/대상 UI 확인.
- 원본 사용자 저장과 백업을 변경하지 않았습니다.

남은 검수
- 사람의 6장 완주와 체감 난이도·장기 성장/경제 균형.
- 실물 게임패드, 다양한 PC·DPI·전체화면, 접근성 사용자 평가.
- 최종 작화·청음 평가. 자동 검사 통과가 이를 대신하지 않습니다.
- 서명·설치 프로그램·온라인 자동 업데이트는 제공하지 않습니다.

정확한 배포 소스 커밋과 파일 SHA256은 manifest.json을 확인하세요.
