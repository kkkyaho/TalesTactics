캐릭터 편성·인터미션 메뉴 개편과 아군 자유 선택 턴을 담은 Windows 공개 테스트 버전입니다.

### 변경 사항

- **전신 모델 편성:** 5×2 캐릭터 모델, 오른쪽 초상화·능력·장비, 병과 필터·정렬·추천 편성.
- **인터미션 UI:** 장비 비교, 상점 상품 카드와 거래 후 잔액, 성장·승급·특성 적용 화면을 통일했습니다.
- **아군 자유 선택 턴:** 맵의 아군·상단 캐릭터 클릭 또는 `PgUp/PgDn`으로 행동할 아군을 고릅니다. 선택을 바꿔도 이동·행동 기록은 유지되며, 대기/방어로 아군 전원 종료 시 적군 턴이 시작됩니다. 기존 SPD/CT도 설정에서 선택할 수 있습니다.

### 다운로드와 저장

아래 **TalesTactics-0.1.0-preview.3-windows-x64.zip**을 새 폴더에 전체 압축 해제하고 `TalesTactics.exe`를 실행하세요. **Source code ZIP은 실행 파일이 아닙니다.** ZIP 안에 저장 백업·무결성 검사 도구와 `START-HERE.txt`가 포함됩니다.

업데이트 전 저장을 백업하세요. 기존 캠페인과 V1/V2 중단 전투를 이어갈 수 있습니다. 새 중단 전투는 **V3**이므로 preview.2로 돌아갈 때는 업데이트 전 저장 백업을 사용해야 합니다. 사용자 저장·개인 음원은 첨부하지 않습니다.

### 검증 범위

Unity 6000.6.0f1 전체 PlayMode **97/97**, 최종 EditMode **133/133**, 최종 관련 PlayMode **4/4** 통과. 편성10·인터미션40·자유 선택 전투10개 화면 조합과 Windows 일반 빌드를 검증했습니다. 기존 빌드 경고4건은 남아 있습니다.

시각 검수는 Editor Game View 기준입니다. Windows 일반 플레이어는 시작 검사이며, 실물 게임패드·다른 PC/DPI·새 규칙으로 사람의6장 완주와 장기 밸런스 검수는 남아 있습니다.
