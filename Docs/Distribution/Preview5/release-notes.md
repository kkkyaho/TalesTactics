- **6장 전장 아트:** 유적 외벽과 석판, 협곡 절벽·계단, 관측소·수문 장식과 장별 원경을 적용했습니다.
- **영웅 모션·상태창:** 영웅 10명의 보행·공격·기술·궁극기 동작과 피격 반응을 보강했습니다. 큰 초상·회전 모델과 능력/기술/장비 탭에서 상세 정보를 확인합니다.
- **전장 가독성:** 배경 대비와 캐릭터 환경색, HP바 겹침 보정, 목표 표식과 기술 모양·사거리·속성 아이콘을 개선했습니다.
- **명령과 준비 화면:** 아군 초상·이동/행동/완료 표시, 대기/턴 종료 구분, 편성 출전 체크, 임무 미니맵·적 병과와 구매 전 장비 비교를 제공합니다.

### 다운로드와 저장

아래 **TalesTactics-0.1.0-preview.5-windows-x64.zip**을 새 폴더에 전체 압축 해제하고 `TalesTactics.exe`를 실행하세요. **Source code ZIP은 실행 파일이 아닙니다.** 저장 백업·무결성 검사 도구와 `START-HERE.txt`를 포함합니다.

업데이트 전 게임을 종료하고 저장을 백업하세요. **preview.4와 저장 형식은 동일합니다.** 캠페인 V1~V3 읽기/V3 쓰기, 중단 전투 V1~V10 읽기/V10 쓰기, 설정 V1입니다. preview.3 이하로 복귀하려면 해당 버전의 저장 백업이 필요합니다. 사용자 저장·로그·개인 음원은 포함하지 않습니다.

### 검증 범위

동일 게임 소스에서 실제 Unity EditMode **202/202**, 최종 PlayMode **126/126**, 상태창360·준비 화면60·전장72조합과 기술126페이지 검사를 통과했습니다. 직전 개발 Windows 실행본으로 독립1장26턴·22공격·승리/저장을 확인했습니다.

릴리즈용 일반 Windows 빌드는 오류0이며 기존 Pipeline/URP 안내3건이 남습니다. 배포 도구 **14/14** 검사를 통과했습니다. 실제 화면 검수는 Editor Game View 기준이며 다른 PC·DPI·실물 게임패드·전6장 수동 완주와 장시간 성능 검수는 별도입니다.
