기술 연출과 전투 조작·정보 조회를 개선한 Windows 공개 테스트 버전입니다.

### 변경 사항

- 기술의 준비·투사체·접촉·잔광을 구분하고 피해 표시·효과음 시점을 맞췄습니다. 마신검·메테오 스톰·썬더 블레이드를 재구성하고 나머지179개 기술 ID에 개별 연출 프로필을 적용했습니다. 기존 전투 판정·피해·소모 자원은 유지합니다.
- 전투 공통 창과 인터미션의 글자·버튼이 장식 프레임 안에 배치되도록 여백과 행 높이를 보완했습니다. 최대6명 편성과 결과 표시를 유지합니다.
- 전장에서 마우스 가운데 버튼을 누르고 드래그하면 맵을 이동합니다. 휠 확대·축소, Q/E 회전, Home 전체 보기도 유지합니다.
- 턴 종료 안내가 실제 출전 아군의 남은 이동·행동과 방향 확정 대기를 구분합니다. 이동·행동을 모두 사용한 유닛에 행동 포기 경고를 표시하지 않습니다.
- 명령 대기 중 적 클릭 → 기술 보기, 또는 임무 적 상세 → 임무 적 기술 보기에서 실제 기술·비용·사거리·범위·효과를 확인합니다. 공격·기술 대상 선택 중 적 클릭은 기존처럼 즉시 사용합니다.
- 전투 결과의 아이템 카드를 클릭하면 능력치·고유 효과·획득/보유 수량과 장착 가능한 합류 동료를 확인합니다. 닫으면 결과로 돌아가며 전투 후 이야기 흐름을 유지합니다.
- 장비 후보에 현재 장착·선택 초안·동료 착용 중과 미장착 수량을 표시합니다. 다른 동료가 모두 사용하는 장비는 비활성으로 보이며 임의로 장비를 해제하지 않습니다.
- 중앙 경험치 알림에 짧은 레벨업 빛 효과와 효과음을 추가했습니다. 축소 효과·효과음 음량·모달 대기를 따릅니다.

### 실행 및 저장

`TalesTactics-0.1.0-preview.8-windows-x64.zip`을 새 폴더에 전부 풀고 `TalesTactics.exe`를 실행하세요. Source code ZIP은 실행용이 아닙니다. 저장 백업·패키지 무결성 검사 도구와 START-HERE.txt를 포함합니다.

업데이트 전 게임을 종료하고 저장을 백업하세요. 캠페인 V1~V3 읽기/V3 쓰기, 설정 V1, 중단 전투 V11을 유지합니다. 구6장 중단 전투는 이어갈 수 없습니다. 구버전 복귀에는 업데이트 전 저장 백업을 사용하세요. 사용자 저장·로그·개인 음원은 배포하지 않습니다.

### 검증 범위

전체 기술 확장 단계에서 실제 Unity PlayMode202/202 및 Windows 아군 기술176/176을 통과했습니다. 이후 최신 피드백 단계는 전체 PlayMode218/220에서 테스트 전제·대기 조건2건을 수정한 뒤 카메라1/1·레벨업3/3, 최종 레이아웃 관련10/10·장비8/8을 통과했습니다. 최종 단일 전체220/220 실행으로 표현하지 않습니다.

최신 Editor Game View는80상태×5해상도×3글자배율1,200/1,200, 최종 Windows 검수 실행본은1902×991×3글자배율×80상태240/240에서 경계·입력 문제와 수집 오류0건입니다. Editor 검수 후의 마지막 보스 요약 문구 조건은 최종 Windows에서 확인했습니다. 사용자 저장·백업·설정8파일 SHA256 불변, 일반 DLL에서 검수 타입 제외를 확인했습니다.

릴리즈 일반 빌드는122.41초, 오류0/경고3이며 Runtime DLL은 직전 검증본과 동일합니다. 배포 도구14개 검사를 통과했습니다. 경고는 Pipeline 런타임 미설정과 URP 내부 디버그 셰이더2개의 제외 안내입니다. 다른 PC/DPI·물리 입력 장치·효과음 실청취·전체 캠페인 수동 완주·장시간 성능은 추가 검수 대상입니다.
