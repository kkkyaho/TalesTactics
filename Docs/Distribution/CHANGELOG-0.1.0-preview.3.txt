TalesTactics 0.1.0-preview.3 — 편성·인터미션 UI / 아군 자유 선택 턴

preview.2 이후 변경
- 출전 편성을 5×2 전신 모델 선택과 오른쪽 초상화·능력·장비 정보로 개편했습니다.
- 병과 필터, 정렬, 추천 편성과 전체 해제를 제공합니다.
- 장비 관리·상점·성장/승급을 남색·청록·황동 디자인으로 통일했습니다.
- 장비 교체 전후 능력치, 상점 상품 카드·거래 후 잔액, 승급 조건·특성 적용을 확인합니다.
- 기본 전투가 아군 전체 → 적군 전체 방식으로 바뀌었습니다.
- 명령 대기 중 맵의 아군·상단 캐릭터·PgUp/PgDn으로 미완료 아군을 자유롭게 선택합니다.
- 선택을 바꿔도 이동·행동·쿨다운·연계 기록은 유지합니다.
- 대기/방어 방향 확정 후에는 재행동할 수 없으며 아군 전원 완료 시 적군 턴이 시작됩니다.
- 기존 SPD/CT 규칙도 전투 규칙 설정에서 선택할 수 있습니다.

저장 호환
- 캠페인 저장 V1 읽기/이관·V2 읽기/쓰기 및 설정 V1을 유지합니다.
- 새 중단 전투 V3는 각 아군의 행동 진행과 현재 선택을 보존합니다.
- 기존 V1/V2 중단 기록은 저장 당시 SPD/CT 규칙으로 복구합니다.
- preview.2는 V3 중단 기록을 읽지 못합니다. 업데이트 전에 저장을 백업하고,
  구버전으로 복귀할 때에는 업데이트 전 백업을 사용하세요.

검증
- Unity 6000.6.0f1: 전체 PlayMode97/97, 최종 EditMode133/133 및 관련 PlayMode4/4 통과.
- 편성10조합, 인터미션40조합, 자유 선택 전투10조합의 해상도/글자 크기 검수.
- Windows x64 일반 빌드 성공. 기존 Pipeline/셰이더 경고4건은 남아 있습니다.
- 실제 게임 화면 검수는 Unity Editor Game View 기준입니다.
- 실물 게임패드·다른 PC/DPI·새 규칙으로 사람의6장 완주/장기 밸런스 검수는 남아 있습니다.

설치
실행용 Windows ZIP을 새 폴더에 전체 압축 해제하고 TalesTactics.exe를 실행하세요.
GitHub의 Source code ZIP은 실행 파일이 아닙니다. START-HERE.txt의 저장 백업과
무결성 검사 절차를 참고하세요. 사용자 저장·개인 음원은 패키지에 포함하지 않습니다.
