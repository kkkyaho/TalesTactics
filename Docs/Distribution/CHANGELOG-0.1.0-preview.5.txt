TalesTactics 0.1.0-preview.5 — Windows x64 공개 테스트

- 6장 전장에 유적 외벽, 협곡 절벽, 관측소·수문 장식과 새 원경/바닥 아트를 적용했습니다.

- 전장 대비와 캐릭터 환경색, HP바 겹침, 목표 표식, 기술 아이콘과 공통 버튼 강조를 개선했습니다.

- 편성 출전 체크, 임무 미니맵·적 병과, 구매 전 장비 비교·가격·완료 안내를 추가했습니다.

저장 호환
preview.4와 저장 형식은 동일합니다. 캠페인 V1~V3 읽기/V3 쓰기,
중단 전투 V1~V10 읽기/V10 쓰기, 설정 V1입니다.
업데이트 전 게임을 종료하고 저장을 백업한 뒤 새 폴더에 전체 압축 해제하세요.
preview.3 이하로 복귀하려면 해당 버전 사용 당시의 저장 백업이 필요합니다.

검증과 한계
동일 게임 소스의 실제 Unity EditMode 202/202, PlayMode 126/126 통과.
상태창360·준비60·전장72조합과 기술126페이지 검사, Windows 독립1장 승리/저장 확인.
배포용 일반 빌드는 개발 검수 코드를 제외하며 기존 Pipeline/URP 안내3건이 남습니다.
다른 PC/DPI·물리 게임패드·전6장 수동 완주·장시간 성능 검수는 별도입니다.
전체 게임의 최종 상용 출시 판정을 뜻하지 않습니다.
