타이틀·인터미션·전투 화면과 편성·장비 UX를 개선한 Windows 공개 테스트 버전입니다.

### 변경 사항

- 타이틀 화면에 새 게임과 저장된 게임 불러오기를 추가했습니다. 슬롯 선택 후 확인하며, 팝업·대화·상태창에 공통 프레임과 차분한 선택 색상을 적용했습니다.
- 인터미션을 다음 이야기 중심으로 단순화했습니다. 전투 전/후 이야기를 진행 흐름에 연결하고, 미합류 동료는 편성·장비·성장·상점 비교에서 숨깁니다.
- 편성은 3열 세로 마우스 휠 스크롤이며 최대6명 출전을 지원합니다. 동료 조회·메뉴 전환에서 스크롤 위치를 유지하고 키보드·패드 선택을 따라 목록을 이동합니다.
- 장비의 현재/후보와 능력치 변화를 비교합니다. 캐릭터별 변경 초안을 유지하고 명시적으로 장착·저장하거나 취소합니다. 상점에서 구매 후 바로 장착할 수 있습니다.
- 초상화와 장비 원화, 직업·출전·명령·전장 일러스트 아이콘을 적용했습니다. 전용무기 장착 외형과 초상화 대화를 추가했습니다.
- 전투 상태·명령 패널을 통합하고 대상·격파·아군 피해·적 반응 예측을 요약했습니다. 원경 대비·카메라·HP바 배치를 조정하고, 경험치 및 전투 결과 화면을 개선했습니다.
- 메인20화·개인 이야기30단계, 기존 전투 규칙과 콘텐츠를 유지합니다.

### 실행 및 저장

`TalesTactics-0.1.0-preview.7-windows-x64.zip`을 새 폴더에 전부 풀고 `TalesTactics.exe`를 실행하세요. Source code ZIP은 실행용이 아닙니다. 저장 백업·패키지 무결성 검사 도구와 START-HERE.txt를 포함합니다.

업데이트 전 게임을 종료하고 저장을 백업하세요. 캠페인 V1~V3 읽기/V3 쓰기, 설정 V1, 중단 전투 V11을 유지합니다. 제거된 구6장 중단 전투는 이어갈 수 없습니다. 후일담 진행 같은 신규 상태를 이전 실행본이 보존한다고 보장하지 않으므로 구버전 복귀에는 업데이트 전 백업을 사용하세요. 사용자 저장·로그·개인 음원은 배포하지 않습니다.

### 검증 범위

실제 Unity6000.6.0f1 EditMode358/358, 그래픽 전체 PlayMode173/173 및 이후 변경 관련 검사를 통과했습니다. 최종 Editor53화면×5해상도×3글자 크기795/795, Windows 현재604×1181 창159/159에서 경계·입력 문제와 수집 게임 오류0건입니다. Windows 데스크톱 크기 제한으로 지정5해상도는 Editor에서 확인했습니다.

릴리즈 일반 빌드는 오류0/경고3이며, Runtime DLL은 직전 검증본과 동일합니다. 배포 도구14개 검사를 통과했습니다. 전체 PlayMode 이후 세부 변경은 관련 검사로 확인했으며 최종 단일 전체 테스트 재실행으로 표현하지 않습니다. 다른 PC/DPI·실물 게임패드·전체 캠페인 수동 완주·장시간 성능은 추가 검수 대상입니다.
