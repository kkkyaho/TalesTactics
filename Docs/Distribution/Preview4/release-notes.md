행동 경험치, 전투 시스템과 전장 UI 개선을 담은 Windows 공개 테스트 버전입니다.

### 변경 사항

- **행동 경험치와 교전 구성:** 공격·유효 회복/지원·처치에 따라 경험치를 얻고 레벨 차이를 반영합니다. 전투 중 100 EXP마다 레벨업하며, 장별 적 구성과 일부 증원을 조정했습니다.
- **전투 선택지:** 난이도와 임무 변형, 선택형 반격·지원 공격, 행동 되감기, 출전 당시 상태로 재도전, 보스 호위 방벽과 전술 특성을 추가했습니다.
- **간결한 UI:** 임무·전투 예측·되돌리기 확인창을 줄이고 상세 설명을 선택형 도움말로 옮겼습니다. 적 정보·행동 상태와 성장 화면도 개선했습니다.
- **캐릭터와 전장 표시:** 제이드·알펜을 포함한 캐릭터 크기를 보정하고 HP 손실 구간·피해 잔상, 이동 경로·도착 미리보기, 접지 그림자와 연결된 위험 영역을 적용했습니다. 대기 방향은 발밑4방향 화살표로 선택합니다.
- **조작과 수정:** 창 최대화·테두리 드래그 크기 조절·창 상태 복원을 지원합니다. 알펜의 행동 후 기술 메뉴가 실제 연계 사용 가능 여부에 맞춰 활성화됩니다.

### 다운로드와 저장

아래 **TalesTactics-0.1.0-preview.4-windows-x64.zip**을 새 폴더에 전체 압축 해제하고 `TalesTactics.exe`를 실행하세요. **Source code ZIP은 실행 파일이 아닙니다.** 저장 백업·무결성 검사 도구와 `START-HERE.txt`를 포함합니다.

업데이트 전 게임을 종료하고 저장을 백업하세요. 캠페인 V1/V2는 V3로 이관하며 기존 경험치 진행률을 변환합니다. 중단 전투 V1~V9를 읽고 새 중단 전투는 V10으로 저장합니다. **새 저장은 preview.3 이하에서 호환되지 않으므로 구버전 복귀에는 업데이트 전 백업을 사용하세요.** 백업 도구는 `.v1.bak`와 `.v2.bak` 이관 보관본을 함께 복사합니다. 사용자 저장·로그·개인 음원은 배포하지 않습니다.

### 검증 범위

Unity 6000.6.0f1의 최종 전체 PlayMode **119/119**, 직전 시스템 검증의 EditMode **202/202**, 최신 방향 UI의 화면·카메라8조합과 Windows 일반 빌드를 통과했습니다. 배포 도구14개 검사와 ZIP/압축 해제 파일 무결성을 확인했습니다. 기존 Pipeline/URP 빌드 안내3건은 남습니다.

이번 패키지는 검증된 최신 WindowsGroundFacing 일반 빌드를 사용합니다. 실제 화면 검수는 Editor Game View 기준이며, 이번 릴리즈 작업에서는 별도의 압축 해제 실행본 플레이 검사를 하지 않았습니다. 다른 PC·DPI·실물 게임패드와 장기 밸런스 검수는 남아 있습니다.
