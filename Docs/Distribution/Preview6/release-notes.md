새 캠페인과 전투 가독성·스킬 연출 개선을 포함한 Windows 공개 테스트 버전입니다.

### 변경 사항

- **새 캠페인:** 메인20화·개인 이야기30단계, 전용 무기10종, 고유 보스20종과60기술, 지형·목표·시련 및 민간인 표시를 추가했습니다.
- **기존6장 제거:** 이전6장 플레이와 해당 중단 전투 이어하기를 제거했습니다. 기존 성장·장비·골드·완료 이력은 유지하고 새 캠페인으로 연결합니다.
- **피해·경험치 표시:** 작은 피해 숫자와 초상화 옆 경험치 게이지, 레벨업 표시를 적용했습니다.
- **대기 방향:** 머리 위의 작고 짧은 베이지색 화살표로 표시하며 사각 배경을 제거했습니다.
- **스킬 연출:** 굵은 화염 흐름, 적을 감싸는 불꽃·연기·잔불과 넓은 검격 잔상, 준비·타격·후속 동작 및 먼지를 강화했습니다. 기존 방향별 캐릭터 원화를 사용합니다.

### 다운로드와 저장

**TalesTactics-0.1.0-preview.6-windows-x64.zip**을 새 폴더에 모두 풀고 `TalesTactics.exe`를 실행하세요. GitHub의 **Source code ZIP은 실행용이 아닙니다.** 저장 백업·무결성 검사 도구와 `START-HERE.txt`를 포함합니다.

업데이트 전 게임을 종료하고 저장을 백업하세요. 캠페인 V1~V3 읽기/V3 쓰기, 설정 V1을 유지하며 중단 전투는 V11입니다. 형식상 V1~V11을 읽지만 **제거된 구6장 중단 전투는 이어갈 수 없습니다.** 새 캠페인/중단 기록은 preview.5 이하에서 지원하지 않으므로 구버전 복귀에는 업데이트 전 백업이 필요합니다. 사용자 저장·로그·개인 음원은 포함하지 않습니다.

### 검증과 한계

최종 게임 코드에서 실제 Unity6000.6.0f1 그래픽 Editor PlayMode **137/137**, API 참조4개 컴파일을 통과했습니다. 앞선 캠페인·전투 표현 단계의 EditMode333/333 결과는 별도 기록이며 이번 릴리즈에서 다시 실행한 결과는 아닙니다. 불꽃/검격의 전체 전장·초점4장면을 실제 실행 경로로 촬영해300프레임·오류0을 확인했습니다.

일반 Windows 빌드는 오류0이며 기존 경고3건이 남습니다. ZIP에 개발 검수 코드를 포함하지 않습니다. 촬영은 배치를 고정한 검수 장면이며 수동 캠페인 완주나 실시간 성능 측정이 아닙니다. 다른PC·물리 게임패드·새 캠페인 전체 수동 완주·장시간 성능은 추가 검수 대상입니다. 인터미션 초상화 대화는 아직 개발안 상태입니다.
