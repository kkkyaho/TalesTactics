경험치 결과 패널

폭 340px, 높이 약 100px. 초상화·이름·레벨·5px 게이지. 행동 종료 후 획득자별로 순서대로 표시하고, 100을 채우면 레벨업 후 나머지를 이어 채웁니다. 전투 입력은 막지 않습니다.

실제 구현

월드 공간 EXP 팝업을 전용 Canvas 패널로 옮깁니다. ExperienceGain에 전후 EXP·레벨 스냅샷을 추가해 큐에 보관하고 빠른 연속 행동·복수 획득자에서도 표시가 섞이지 않게 합니다. EXP 계산과 저장 규칙은 유지합니다.

높은 지형에서도 보이는 작은 방향 선택.

대기·방어 시 캐릭터 머리 위에 22px 화살표 네 개를 띄웁니다. 선택 방향만 황금색으로 밝히고, 클릭 영역은 넉넉하게 유지합니다.

머리를 기준으로 배치

캐릭터 렌더러의 실제 상단 좌표를 화면 좌표로 변환합니다. HP바와 12px 간격을 두고, 화면 끝에서는 위치를 보정합니다. 지형의 깊이 검사와 분리해 계단·기둥 뒤에서도 보입니다.

크기는 작게, 입력은 편하게

화살표는 22px, 클릭 영역은 38×38px, 전체 약 104×90px. 화면 확대에 따라 함께 조절합니다. 선택 시 이름·색·선명도가 함께 바뀌며 원래 마우스·키보드 확정/취소 동작을 유지합니다.

카메라와 방향의 일치

카메라 4회전에 맞춰 실제 월드 방향과 화면의 화살표를 연결합니다. 동료 HP바·명령창과 충돌하지 않게 배치하고, 대기 선택을 끝내면 즉시 사라집니다. 시안의 회전 버튼은 방향 매핑 설명용입니다.

불꽃은 불꽃으로. 검격은 몸 전체로.

현재 선·원형 도형 중심 효과에 속성별 재질과 애니메이션을 더합니다. 이펙트와 캐릭터의 준비·접촉·후속 동작을 하나의 타이밍으로 맞춥니다.

AI 생성 효과 콘셉트 보드. 최종 Unity 화면과 제작 완료된 스프라이트가 아닙니다. 기존 전장·캐릭터 비율을 참고했습니다.

TIMING STUDY · 1.05s

검격 / 격투 / 방패를 분리

검격은 몸통 회전과 칼끝 궤적, 격투는 짧은 연속 접촉과 충격파, 방패는 낮은 자세·밀어내기·먼지로 구별합니다. 준비 자세와 후속 자세는 기존 방향별 원화와 연결하고 부족한 원화를 보충합니다.

일반 검격 기준 타이밍

0–0.20s발을 고정하고 상체·검을 뒤로 당깁니다.
0.20–0.36s전진과 몸통 회전, 칼끝을 따라 짧고 두꺼운 궤적.
0.36–0.44s접촉 80ms 정지, 타격점 섬광·피격 반동. 피해 계산은 정확히 한 번.
0.44–1.05s검의 관성이 남는 후속 자세와 복귀. 잔상은 빠르게 소멸.

불꽃

12–16프레임 화염 시트 + 입자. 발광 중심·외곽 화염·잔불·연기를 겹쳐 방향성과 부피를 만듭니다. 준비 0.2초 → 발동 0.45초 → 잔불 0.4초를 출발점으로 조정합니다.

다른 속성

얼음은 결정 생성·파편, 번개는 불규칙 방전·짧은 섬광, 물은 물기둥·포말, 바람은 휘감는 난류, 대지는 지면 균열·파편, 빛·어둠은 각각 광원·응집 소용돌이로 표현합니다.

기술별 연결과 검증

영웅의 기존 기술과 보스 60기술을 속성·무기·범위·접촉 타이밍별로 매핑합니다. 미리보기·실제 타격·다단·광역에서 동일한 패턴을 쓰고, 효과 풀링과 최대 동시 입자 수를 둡니다. 화면 흔들림·섬광 감소 설정도 연결합니다.

대사 데이터 정리

이름 문자열만으로 찾는 대신 speakerId·표정·좌우 위치를 대사에 연결합니다. 내레이션은 초상 없는 별도 배치, 초상이 없는 NPC는 명확한 기본 배치를 사용합니다. 기존 대사·선택·보상 순서는 유지합니다.

넘기기와 읽기

클릭·Enter로 다음 대사, 빠른 전체 표시와 건너뛰기 동작을 유지합니다. 글자 크기 설정을 반영하고 긴 대사는 페이지로 나눕니다. 초상 교체 시 패널 높이가 흔들리지 않도록 고정합니다.
