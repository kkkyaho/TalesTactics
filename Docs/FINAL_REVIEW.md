## 저장 보호와 재현

`ManualReview/save-integrity.json`에 일반 사용자 저장/백업의 전후 해시와 검수 저장의 패배 전/재실행 후 해시를 기록했다. `ManualReview/campaign.json`은 검수 전용 결과이며 사용자 저장이 아니다.

```powershell
./Builds/ManualReview/TalesTactics.exe --manual-review <GUID-N> -screen-fullscreen 0 -screen-width 1280 -screen-height 800
./Tools/MeasurePlayerProcess.ps1 -TargetProcessId <PID> -OutputPath <CSV> -Minutes 30
```

데이터는 `persistentDataPath/ManualReviews/<GUID>`에 저장된다. 새 검수에는 새 GUID를 사용한다. 저장 복원 검사에서 같은 GUID를 재사용할 때는 이전 performance.csv/hardware.txt를 먼저 보존한다(재실행 시 덮어씀). 개발 빌드 전용이며 전투 명령을 대신 선택하지 않는다.

실제 Gamepad 장치는0개여서 USB/Bluetooth 물리 컨트롤러별 검수는 남아 있다. 사람의 난이도·장기 성장 평가와 전문가의 원작 외형/음악 감수는 별도 후속 품질 작업이다.
