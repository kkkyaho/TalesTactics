# 아트·음향 품질 점검과 기술명 대비 보강

2026-10-07. 이번 변경은 기술명 표시 가독성 보완과 현재 에셋의 기술적 품질 점검이다. 기존 그림·음원·전투 규칙은 변경하지 않았다.

## 변경

기술명은 밝은 글자와 반투명 어두운 배경을 사용한다. 일반 기술의 기본 글자 크기를2.8→3.4로 올리고, 긴 이름은 생성 시 한 번 측정하여 최대 폭 안에 한 줄로 맞춘다. 표시 중 AutoSize를 반복하지 않는다. 속성색은 준비 고리에 유지한다. 카메라 회전 시 글자/배경이 함께 회전하며 발동 또는 재출전 시 제거된다.

## 에셋 점검

- 현재20종 캐릭터·적의1012개 스프라이트 참조(캐릭터별 중복 제거), 기본4방향 누락·텍스처 밖 사각 경계·비정상 PPU0건.18개 오디오 참조 모두 연결됨. asset-inventory.json.
- 추가 동작 시트20장/320칸의 알파 측정: 빈 칸·셀 경계 접촉/잘림0건. alpha-audit.json. 이 측정은 추가 동작 시트에 한정되며 모든 원본 픽셀에 대한 미술 감수를 뜻하지 않는다.
- 기존 AnimationPolish의 영웅/적4방향 갤러리8장을 다시 비교했다. 검토한 그림에서 머리·무기·망토 경계 잘림이나 다른 캐릭터의 혼입을 발견하지 못했다. 새로 렌더링한 갤러리가 아니며 이번 변경으로 원화/스프라이트 참조를 수정하지 않았다.
- 음악14곡과 효과음4개 원본 WAV에서 빈 데이터·완전 무음·PCM 클리핑0건. 음악14곡의 기존 manifest SHA256도 일치했다. audio-audit.json 및 ../music-signal-review.json. 소스 PCM 측정이며 실제 혼합 출력의 최대 피크·헤드폰/스피커 품질·사람의 청음 승인은 아니다.
