# 전체 기술 합성 음향

`SkillAudioPalette.cs`에 고정 `ArteProfile`이 있는 ID만 새 음향군으로 연결했다. 기존 마신검·메테오 스톰·썬더 블레이드는 우선 선택되어 소리를 유지한다. 알 수 없는 ID와 기존 공통 family의 처리도 유지한다. 원작 녹음은 사용하거나 다운로드하지 않았다.

|---|---|---|
| arte-arrow | 활시위, 화살 바람, 짧은 접촉 | 0.28 / 0.32 |
| arte-rifle | 짧은 기계음과 총격 | 0.25 / 0.30 |

검·화염·얼음·번개·일반 회복 형태는 기존 합성 음향군을 재사용한다. 위의 형태와 명칭은 이 프로젝트의 합성 설계이며 원작 녹음이나 청각적 복제라는 뜻이 아니다. 모든 파형은 기존 로컬 xorshift와 계산식으로 생성하며 전투 RNG에 접근하지 않는다. 음향 반복은 별도의 피해·MP·EXP 처리를 호출하지 않는다.

`BattleAudio.cs`는 변경하지 않았다. family 키별 45ms 중복 억제, 전체 4음성 제한, 동시 음성 감쇠, 효과음 볼륨, 음소거, reduced 0.72 배율 및 클립 정리는 기존 경로를 사용한다.

## 검증

[엔진 독립 합성 결과](Validation/audio-synthesis.json)는 실제 C# 팔레트 코드를 최소 `AudioClip`/`Mathf` 대역과 컴파일해 검사한 결과다. Unity 재생·수명주기·믹서 검증으로 표현하지 않는다.

- 기존 9개 family 및 unknown/null/empty의 두 phase, 총 24쌍 PCM이 변경 전과 비트 단위로 일치했다.
- unknown ID의 속성·스타일·궁극기·효과 990조합과 기존 trio 3개 경로가 유지됐다.
- 새 프로필 179개가 유효한 음향군으로 연결됐다.
- 새 24개 cue는 모두 결정적이며 서로 다른 PCM을 생성했다. NaN/Infinity 없음, 최대 진폭 0.7200001 이하, 실제 길이 0.25002268~0.9500227초였다.
- 모든 새 cue의 첫 샘플은 0, 마지막 샘플 절댓값은 0.00003182 이하였다.

**실청취 미검증.** 이번 검증에는 실제 스피커/헤드폰의 청취 평가가 포함되지 않는다. 음악과 겹칠 때의 인지성 및 체감 균형은 숫자 검사만으로 확정하지 않았다.
