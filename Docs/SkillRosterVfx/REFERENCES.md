# 아군 전체 기술의 원작 자료와 개별 연출 설계

조사일: 2026-10-17. 조사 시작 기준: `develop` / `37e41a1`.

이 문서는 원작 관찰 사실, 영상의 설명·시간표로만 확인한 내용, TalesTactics용 디자인 제안을 구분한다. 대상 목록은 실제 `Assets/TalesTactics/Content/Skills/*.asset`에서 읽었다. 아군 일반 기술 68개(기존 적용 3개 포함), 궁극기 10개, 기본 공격 10개로 총 88개 ID다. 적 기술은 이 문서 범위가 아니다.

## 확인 수준과 한계

- **O — 직접 관찰:** 앞선 작업에서 브라우저로 실제 원작 프레임을 확인한 `cless.0`, `jade.3`, `jade.6`만 해당한다. 정확한 관찰 구간·판본·내용은 [이전 조사 기록](../OriginalSkillTrio/REFERENCES.md)에 있다.
- **M — 영상 자료 확보:** 원 업로더의 영상 제목·설명·시간표를 웹 검색으로 확인했다. 이번 조사에서는 프레임을 직접 재생하지 못했다. 시간표가 있어도 해당 기술의 색·모션을 직접 검증했다는 의미가 아니다.
- **T — 공식 텍스트 확인:** 공식 사이트가 명시한 무기·기술 설명만 확인했다. 사진을 읽지 못한 경우 시각 관찰로 처리하지 않았다.
- **U — 미관찰:** 해당 기술의 원작 구간 또는 정확한 판본을 직접 확인하지 못했다. 아래 제안은 현행 이름·효과와 게임의 가독성을 기준으로 한 디자인이며 원작 재현 사실이 아니다.

이번 세션의 CUA `getState()`는 사용 가능한 브라우저가 없었고, `iab`/`chrome` 생성과 `getBrowser({url})`도 실패했다. 따라서 **신규 65개 일반 기술의 원작 프레임을 전부 관찰했다거나 88개를 원작과 동일하게 재현했다고 표현하지 않는다.** 원본 동영상·음원·텍스처를 다운로드하거나 추출하지 않았다. 기존 세 기술의 관찰을 나머지 기술의 근거로 확대하지 않는다.

아래의 색·개수·시간차·궤적은 별도로 O라고 명시한 관찰을 제외하면 **전술 화면용 제안**이다. 구현 완료·실행 검증 결과는 별도 구현/검증 문서가 우선하며, 이 조사표가 실제 구현 목록을 대신하지 않는다.

## 개별 연출 설계 원칙

1. 각 ID에 **주 형상 + 발생 위치/궤적 + 전개 순서 + 시전자 포즈**를 둔다. 같은 메시의 색·크기만 바꾸는 것으로 완료하지 않는다.
2. 같은 원화를 공유해도 하나의 저공 파동, 연속 찌르기, 두 개의 파동, 상하 베기, 불새, 무거운 낙하 등 화면에서 읽히는 사건이 달라야 한다.
3. 아군 6명이 밀집해도 주인공의 무기와 대상이 보이도록 큰 형상은 접촉 근처에 짧게 유지한다. 전체 화면 백색 섬광이나 모든 대상에 동일한 대폭발을 복제하지 않는다.
4. 후속 운석·검격·파편은 시각 리듬이다. 피해·MP·HP 비용·게이지·난수 판정은 기존 해석기의 1회 실행을 보존한다. 타격 수처럼 보이는 효과를 실제 추가 판정으로 만들지 않는다.
5. 축소 효과는 형상의 정체성을 남긴다. 사자는 사자 실루엣, 망치는 망치, 얼음은 결정, 방패는 방패가 남아야 하며 모든 기술을 링 하나로 바꾸지 않는다.
6. 회복·정화·부활·부활 보험·자기강화는 서로 다른 의미다. 원작에 같은 이름이 있어도 현행 Content가 우선이다.

## 검수에서 반드시 나눌 의미

- `velvet.0`: 사거리 0 자기강화, HP 비율 비용. 적에게 피해를 준 것처럼 숫자/피격 효과를 만들지 않는다.
- `velvet.2`: 현행 자기중심 광역 및 게이지 변화. 원작의 클로 분류를 이유로 대상 선택/사거리/자원 규칙을 바꾸지 않는다.
- `natalia.6`: `AutoRevive`, 지속 5턴. 현재 살아 있는 대상에게 걸리는 자동 부활 상태를 새 부활과 구분한다.
- `mint.5`, `mint.6`, `tear.5`, `shionne.6`: 실제 `Revive` 효과 및 쓰러진 아군 대상. 같은 이름의 원작 회복술을 그대로 옮겨 HP 회복만 보여주지 않는다.
- `kisara.0`: 적에게 피해를 주고 시전자에게 회복하는 두 의미. 광역 중심 연출과 자기 회복의 공간을 분리한다.
- 원작 영상의 긴 카메라 컷·음성·일시정지·다단 피해 수는 이 전술 게임에 자동으로 복제할 대상이 아니다. 영상·음원 추출은 하지 않으며, 시각 리듬과 규칙 판정은 별개로 유지한다.

## 후속 원작 관찰 우선순위

1. 직접 재생 가능한 환경에서 R1/R2의 위 시간표를 확인하여 각 일반 기술의 방향·순서·주 색을 확정한다.
2. 키사라 R3에서 Flaming Meteor/Igneous Discharge/Blizzard Bloom을 먼저 확인한다. 이름만으로 잘못 해석하기 쉬운 기술이다.
3. P2의 Nurse/Piko Hammer와 벨벳 네 Claw를 관찰하여 단순 추상 효과가 핵심 형상을 대신하지 않게 한다.
4. P1의 차원참/시공창파참·궁극기 수록 판본을 확인하고, 미수록이면 그 판본의 기술이라고 표시하지 않는다.
5. A2/A3의 치유·부활·화살 궤적을 확인한다. 이 작업이 완료되기 전에는 '전체 기술 원작 고증 완료'라는 표현을 사용하지 않는다.
