# 원화·음향 출처와 제작 범위

두 아틀라스는 이번 작업에서 built-in `image_gen`으로 새로 생성했다. 원작 게임에서 추출하거나 다운로드한 이미지·모델·음원이 아니다. 캐릭터/기술 이름과 전술 규칙은 기존 프로젝트 데이터다. 원작 참고의 확인 수준은 [REFERENCES.md](REFERENCES.md)를 따른다.

## 제작 지시 요약

아래는 생성 프롬프트의 핵심 요구를 요약한 기록이며, 도구 입력을 그대로 인용한 전문이 아니다.

- 공통: 투명 배경의 4×4 스킬 효과 아틀라스. 텍스트·로고·테두리 없이 어두운 판타지 전술 전장 위에서 읽히는 정교한 빛/물질 실루엣. 각 셀 가운데에 독립 효과를 배치하고 주변에 투명 여백을 확보한다.
- 무기 시트: 검의 초승달 궤적, 분홍 마법 망치, 상승 검기, 관통 창, 청록 사자, 붉은 발톱, 화염 검호, 화살, 총구 섬광, 수류탄 폭발, 방패, 불사조, 용, 주먹 충격, 금빛 시계, 보라 구속장.
- 주문 시트: 얼음 결정, 물결, 회오리, 솟는 암석, 화염 기둥, 성스러운 빛기둥, 프리즘 검, 회복 연꽃, 정화 나비, 부활 날개, 보호막, 수면의 달, 중력 소용돌이, 정교한 시전 문양, 노래의 리본, 유성.
- 무기 시트 첫 결과는 망치 형태와 셀 여백이 맞지 않아 수정 생성했다. 최종 두 이미지를 직접 확인한 뒤 적용했다. 원본 셀 바깥 잔광은 전용 셰이더의 가장자리 투명 감쇠로 처리하며, 전투 캡처를 별도로 검수한다.

최종 PNG는 1254×1254 RGBA, 4×4 셀이다. 무기·마법 시트를 각각 하나의 공유 머티리얼로 사용하고 기존 네 메시 구조와 16개 풀 상한을 유지한다. 기본 원화 32개에 기술별 개수·배치·속도·색·발사/낙하·보조 효과를 조합한다. 179개의 서로 다른 원화/애니메이션을 각각 제작했다는 뜻은 아니다.
