# 전체 기술 연출 확장 — 2026-10-17

기존 마신검·메테오 스톰·썬더 블레이드 3종을 보존하고 **나머지 179개 기술**에 ID별 연출 설정을 연결했다. 아군은 일반기·궁극기·기본공격을 합쳐 88개이며 이번에 바뀐 것은 85개다. 적·보스·전술 기술 94개도 포함한다. 전체 카탈로그는 182개다.

## 적용한 변화

- 검격·연속 찌르기·발톱·사자/용/봉황·화살/총격·방패와 화염 해머의 이동·접촉 모양을 구분했다. 준비, 도약/돌진/시전, 이동 효과, 접촉, 잔광이 연결된다.
- 바위·물·바람·얼음·빛·중력·회복·정화·부활·보호·노래·시간 정지·구속을 각 형상과 배치로 표현한다. 민트의 낙하 피코 해머와 키사라의 근접 화염 해머를 구분한다.
- 큰 사자·용·봉황 형상은 하나만 표시하고 후속 반복은 작은 충격광과 파문으로 처리한다. 광역 기술은 큰 중심 효과 하나와 각 대상의 작은 접촉 표시를 사용한다.
- 일반/축소 효과는 같은 판정 결과를 사용한다. 축소에서는 시각 반복 수와 불투명도를 줄인다. 흡혈로 시전자가 회복할 때는 공격 모양 대신 별도 회복 효과가 나온다.
- 생성 원화 32개를 두 장의 4×4 투명 아틀라스에 넣고 기술별 배치·크기·색·반복·보조 효과를 조합했다. 179개 모두의 원화를 각각 제작했다는 뜻은 아니다. 효과음은 새 12계열×준비/접촉 24개를 합성했다.

Core, Content 에셋, 위력·MP/HP 비용·사거리·격자 이동 규칙, 저장 형식은 변경하지 않았다. 후속 검격과 폭발은 시각 연출이며 전투 판정을 추가하지 않는다.

## 촬영과 수정 이력

기준선은 `37e41a176e664907e2ffba1f782a2da586766554`이며, 기존 렌더 코드를 보존한 채 새 검수기만 추가해 대표 20개를 먼저 촬영했다. [기준선 보존 검사](Validation/baseline-integrity.json). 이후 같은 훈련 배치·캐릭터·6인 구성·기본 카메라로 촬영했다. 양쪽 모두 TalesTactics 실제 실행이며 원작 상용 게임 영상과의 비교가 아니다. 기술별 소요 시간은 의도적으로 다르다.

첫 변경본도 20/20 판정 검사를 통과했지만 사자 형상이 여러 겹으로 겹쳐 가독성을 해쳤다. 큰 형상 하나와 작은 후속 충격으로 수정하고 대표 20개를 다시 촬영했다. 첫 결과는 `Validation/after-first-editor.json`에 남겼다. 이후 대표 20개에 포함되지 않은 Hammer의 근접/낙하 분기와 색상만 보완했고, 민트·키사라 두 기술을 일반/축소로 별도 실행했다. 최종 전체 테스트와 Windows 실행은 이 마지막 수정까지 포함한다.

검수기는 레벨·배치·상태·격리 저장을 준비한 뒤 실제 `BattleDirector.Execute`를 호출한다. 전투 규칙을 우회하는 가짜 효과 재생만으로 아군 실행 성공을 판단하지 않는다. 적 94개는 이번 전수 검사에서 렌더만 확인했으며 모든 적 AI의 실제 시전·배속을 전수 실행했다고 주장하지 않는다. 부활은 KO 모델의 비활성 상태까지 포함해 6인 구조를 확인한다.

## 확인 범위와 한계

기존 3종 외 원작 영상은 이번 환경에서 직접 재생 관찰하지 못했다. 나머지는 기술명·기존 프로젝트 SourceNote·공식/보조 설명을 근거로 재해석했으며 REFERENCES.md의 관찰 등급을 따른다. 원작 모델·관절 애니메이션·카메라·프레임·성우/효과음을 그대로 복제한 구현이 아니다. 보스에는 프로젝트 창작 기술도 있다.

32개 실루엣과 기존 SD 포즈를 조합한다. 원작과의 정확한 일치, 오디오 실청취, 전체 캠페인 수동 완주, 모든 적 AI 배속, 다른 PC/GPU/DPI, 장시간 성능은 미검증이다. 30fps 고정 촬영은 성능 벤치마크가 아니다. 머리 위 이름/기술명 겹침과 하단 직전 기술 메시지 잔류는 기존 HUD 한계이며 이번 효과 확장 범위에서 수정하지 않았다. 이번 표현 계층 작업에서는 EditMode를 다시 실행하지 않았다. main과 공개 릴리즈는 변경하지 않는다.
