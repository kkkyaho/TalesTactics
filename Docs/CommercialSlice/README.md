# 대표 초반 전투·성장·이야기 개선

## 적용 범위

이번 작업은 상용 SRPG 비교에서 확인한 부족한 부분 중 대표 경험을 만드는 첫 적용이다. 메인 1~3화의 공략 차별화, 크레스·민트의 기존 성장 방향에 전술 효과 추가, 장별 이야기 배경과 전장 가독성을 다룬다. 기존 보상 비교 변경도 함께 실행 검증한다. 메인 4~20화 전체 재설계나 모든 캐릭터의 새 성장 분기, 감정별 새 초상 원화, 일반 적 AI의 협동 전술은 이번 구현 범위가 아니다.

- 1화: 중앙 다리로 전진해 구조 신호 1곳 연결과 수호자 격파.
- 2화: 좌우 감옥 장치 2개 파괴 후 남쪽 퇴로 도착. 보스 격파는 필수가 아니다.
- 3화: 세 다리 너머 구조 신호 3곳 연결 후 북쪽 탈출. 경로와 인원 분배를 선택한다.
- 기존 중단 저장·재시도는 저장된 전투 개정 번호가 없으면 종전 맵·목표를 사용한다. 신규 1~3화 전투만 새 규칙으로 시작한다. 개인 이야기의 맵은 유지한다.
- 크레스 Lv10 돌파는 이동 후 기본공격으로 일반 적 1칸 밀침, 수호는 방어 중 인접 동료 피해 1회 감소. 민트 Lv10 돌파/수호는 실제 단일 회복 후 각각 공격 지원/방어 지원. 저장 enum과 해금 조건은 유지한다.
- 이야기 화면은 기존 장별 원경 원화를 재사용하고 화면 비율에 맞춰 잘라 표시한다. 초반 장소 표시와 대화 공간을 보강한다. 새 감정 초상이나 동영상 연출을 추가한 것은 아니다.
- 전장 원경의 채도와 대비를 낮춰 전술 유닛·표식이 먼저 읽히도록 조정한다. 기존 2.5D·카메라·원화 스타일을 유지한다.

## 검증 완료 — 2026-11-17~18

EditMode는 마지막 UI 수정 전 실행이며 전투 규칙 소스는 이후 바뀌지 않았다. 최종 PlayMode는 커서·보상창 수정까지 포함한다. 표적 검사 수를 전체 결과에 합산하지 않는다.

Windows 자동 진행은 기존 전투 우선 정책의 Standard 난이도·4배속 실행이다. 2~3화에서 보스를 남기고 승리할 수 있는 규칙은 별도 Core 검사로 확인했으나 이 자동 완주가 사람의 우회 공략·난이도·재미·플레이시간을 입증하지는 않는다. 실제 결과 화면과 1화 전장을 육안 확인했으며 [원본 캡처와 범위](Evidence/windows-visual-review.json)를 남겼다. 48장 모두의 수동 검수는 아니다.

초기 EditMode 536/537은 공격자 방향 설정이 빠진 테스트를 실제 Director 호출 순서에 맞춰 수정했다. UI 최초 실패, 0건 발견, 재로드 시간 초과는 성공으로 세지 않고 보존했다. 첫 실제 일반 빌드는 BuildReport상 성공했으나 폰트 입력이 바뀌어 소스 연결 검증을 거부했다. 생성본을 보존하고 초기 폰트를 다시 불러온 뒤 두 빌드의 입력 일치를 통과했다. 초기 PowerShell5 호출 실패의 일부 고정 파일은 후속 시도에 덮어써져 원문 전체가 남지 않았으며, [재구성 진단](Validation/build-dispatch-attempt1.json)을 원문으로 표현하지 않는다. 기존 Pipeline 설정·내부 디버그 셰이더·폐기 예정 검수 API 경고는 빌드 기록에 남겼다.

[최종 보존 검사](Validation/final-preservation.json)에서 작업 전 사용자 수정12파일과 실제 루트 저장·설정9파일은 동일하다. 테스트가 StorageTests에130파일·70폴더를 추가하고 TestResults.xml을 갱신했으므로 작업 전체의 사용자 트리가 불변인 것은 아니다. Windows 실행 구간의 재귀 사용자 트리는 별도 전후 비교에서 동일했다. [Editor 상태](Validation/editor-final-state.json)와 GameView를 초기 상태로 복원했다.

## 사람의 플레이로 확인할 부분

처음 하는 사람 3~5명에게 설명 없이 첫 30분을 플레이하게 하는 후속 검수가 필요하다. 자동 완주는 아래 체감 결과를 대신하지 않는다.

- 각 화에서 목표와 다음 행동을 스스로 설명할 수 있는가.
- 2화에서 적 전멸을 시도하지 않고 퇴로 목표를 이해하는가.
- 3화에서 인원을 나누거나 한쪽부터 처리하는 선택의 이유가 생기는가.
- 크레스·민트의 두 성장 방향을 보고 운용 차이를 예상할 수 있는가.
- 배경보다 활성 캐릭터·위험·목표가 먼저 눈에 들어오는가.
- 보상을 받은 뒤 누가 쓰면 좋은지 판단하고 정비까지 이어가는가.
