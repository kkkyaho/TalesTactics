현재 캡처와 개선안을 함께 표시합니다. 좁은 화면에서는 세로로 배치됩니다.

01

전투 화면

전경의 전투 공간을 넓게 잡고, 선택한 동료의 상태와 명령을 한곳에서 읽습니다.

기존 아군 턴 자유 선택 흐름을 전제로 합니다. 여섯 동료의 선택·행동 가능·완료 상태를 구분해 표시하는 방향입니다. 시안의 지형·유닛 배치는 구도 설명용이며 실제 타일 위치를 재현한 검증 결과가 아닙니다. 이미지에서 축약된 SP·능력·전술 도움말은 실제 구현 시 접근 경로를 유지합니다.

01

전투 공간에 시선 모으기

현재
원경과 지면의 세부 표현이 전장 정보와 시선을 나눕니다.
제안
배경·바닥 대비를 낮추고, 카메라 전경에 실제 전투 공간을 확보합니다.
효과
이동할 칸과 캐릭터의 위치를 더 빨리 찾습니다.
02

상태와 명령을 가까이

현재
선택한 동료의 상태와 다음 명령을 떨어진 영역에서 확인합니다.
제안
선택 동료의 상태·명령을 묶고, 대상 선택 시 예측 요약을 같은 영역에 둡니다.
효과
캐릭터 확인에서 행동 결정까지 시선 이동을 줄입니다.
03

여섯 동료의 상태를 한눈에

현재
작은 초상과 표식에서 선택 상태와 행동 완료를 함께 읽어야 합니다.
제안
6명의 HP·이동·행동 상태를 같은 규칙으로 정리하고 완료 표시를 분리합니다.
효과
아직 움직이거나 행동할 수 있는 동료를 쉽게 찾습니다.
02

6명 편성

캐릭터의 정체성과 출전 상태를 같은 카드에서 읽고, 조회와 출전을 분명하게 구분합니다.

출전은 총 6명입니다. 이 페이지에서 5명이 출전 중이며, 나머지 1명은 다음 페이지에 있습니다. 현재 페이지의 나탈리아는 미출전 상태입니다.

01

한 카드에 한 동료

현재
모델과 이름·레벨·상태를 여러 위치에서 함께 확인합니다.
제안
이름·레벨·출전 상태를 카드 안의 일정한 위치에 모읍니다.
효과
동료를 식별하고 여섯 자리의 구성을 비교하기 쉬워집니다.
02

조회와 출전을 구분

현재
조회 중인 동료와 출전 중인 동료의 표시를 함께 해석해야 합니다.
제안
조회 선택은 청록 테두리로, 출전은 별도 휘장과 문구로 표시합니다.
효과
상세 조회만 해도 출전이 바뀌는 듯한 혼동을 줄입니다.
03

확정에만 강한 강조

현재
편성 변경·조회·다음 단계의 조작이 비슷한 강도로 보입니다.
제안
확정 버튼을 가장 강하게 강조하고, 기존 필터·정렬·페이지를 유지합니다.
효과
익숙한 탐색을 유지하면서 다음 행동을 분명히 안내합니다.
03

장비 정비

현재 장비와 교체 후보를 가까이 놓고, 초안에서 저장 완료까지의 상태를 명확하게 만듭니다.

현재 캡처는 후보 선택 전, 개선안은 청동검을 선택한 저장 전 초안의 예시입니다. 공격 +4는 기존 장비 데이터이며 새 보너스를 추가한 것이 아닙니다. 장착하고 저장 이후에만 실제 적용 상태로 바뀝니다.

01

현재와 후보를 나란히

현재
장비 선택과 변경 수치를 각각의 영역에서 찾아 비교합니다.
제안
현재 장비와 후보를 붙여 놓고 주요 능력치 차이를 같은 행에 둡니다.
효과
무엇이 얼마나 달라지는지 한 번의 시선으로 확인합니다.
02

재고는 짧고 명확하게

현재
후보를 살피며 보유 수량과 실제 교체 가능 여부를 확인해야 합니다.
제안
장비명·핵심 효과·수량을 간결한 목록으로 묶고 선택 후보를 강조합니다.
효과
목록을 훑고 교체할 장비를 고르는 시간을 줄입니다.
03

초안에서 저장까지 분명하게

현재
후보 미리보기와 실제 저장된 장비를 구별해 기억해야 합니다.
제안
적용 중 / 저장 전 초안을 명시하고 확정 문구를 ‘장착하고 저장’으로 통일합니다.
효과
변경이 적용되는 시점을 이해하고 안심하고 비교합니다.

작은 화면에서도 남겨야 할 것

1024 × 768 설계 메모 · 후속 구현 사양

위 이미지는 데스크톱 화면을 위한 시안입니다. 아래는 좁은 게임 화면에서의 배치 원칙이며, 해당 해상도로 구현하거나 검증한 결과가 아닙니다.

전투 · 결정할 정보부터

명령과 예측을 동시에 펼치지 않고 현재 단계에 맞는 한 영역을 표시합니다. 아군 상태와 전투 공간은 계속 볼 수 있게 유지합니다.

편성 · 3열 × 2행 유지

여섯 카드를 유지하면서 부가 설명을 접습니다. 이름·레벨·출전 상태와 필터·페이지 이동은 바로 확인할 수 있게 남깁니다.

장비 · 비교와 확정 우선

큰 캐릭터 모델을 접고 현재 / 후보 비교와 장착·저장 버튼을 유지합니다. 외형 미리보기는 필요할 때 펼칩니다.

예측 요약·구매 후 바로 장착·캐릭터 전환 시 초안 보존은 추가 UX 제안이며 현재 구현 완료가 아닙니다.
