# 그래픽·UX 비교 시안 — 2026-10-15

이 자료는 구현 전 디자인 제안이다. 게임 코드·콘텐츠·저장 데이터는 변경하지 않았으며, 새 Unity 실행 화면이나 빌드 완료 결과로 사용하지 않는다.

[비교 페이지](index.html)에서 실제 화면과 개선안을 나란히 보고, 현재/개선안 단독 보기와 원본 픽셀 확대를 사용할 수 있다. 외부 라이브러리·폰트·네트워크 자산이 없는 로컬 HTML이다. 좁은 브라우저에서는 두 이미지를 위아래로 배치한다.

현재 PNG 3장은 기준 소스 `3834a36`의 IllustratedIconsReview 실행 캡처를 바이트 변경 없이 복사했다. 원본 검수 실행 ID는 `262bea8d75804470888d2ab63142ca62`이다. `current-battle.png`는 `battle-done-1920.png`, `current-formation.png`는 `formation-six-1920.png`, `current-equipment.png`는 `장비 관리-1920.png`를 사용했다. 모두 1920×1080이며 복사본의 SHA-256 일치를 확인했다.

개선안 3장은 built-in `image_gen`으로 생성한 1672×941 이미지다. 기존 실행 캡처를 참조했지만 지도 메시·타일·캐릭터 픽셀을 그대로 재현한 엔진 출력은 아니다. 세부 광원·재질·장식은 디자인 방향이며 그대로 적용되었다고 해석하지 않는다.

## 상태와 규칙을 보존하는 구현 기준

- 전투의 아군 턴 자유 선택을 유지한다. 상단 6명은 행동 순서 타임라인이 아니다. 이동·행동·완료 상태, 위협 범위, 반격/지원 예측과 취소 경로를 보존한다.
- 전투 시안은 명령 대기 상태다. 아직 고르지 않은 공격의 피해량을 표시하지 않는다. 지형·유닛의 정확한 좌표는 구도 설명에 맞춰 달라졌으며 논리 지도 변경을 제안하는 것은 아니다. 이미지에서 축약된 SP·능력·전술 도움말도 실제 구현에서는 접근 경로를 유지한다.
- 편성 원본은 총 출전 6명 중 현재 페이지에 5명, 다음 페이지에 1명이 있다. 현재 보이는 나탈리아는 미출전이다. 시안도 이 상태와 3열×2행/페이지 이동을 유지한다. 모델 클릭은 조회, 출전 버튼은 추가/제외로 구분한다.
- 장비 원본은 후보 선택 전이며 시안은 청동검을 선택한 미적용 초안 예시다. 실제 `BronzeSword.asset`의 STR +4를 사용하고 다른 보너스는 제안하지 않았다. '장착하고 저장' 이후에만 실제 장비와 저장값이 바뀌도록 한다.
- 시안의 장식용 표식·문구 생략은 기존 게임 기능 삭제나 새 스탯/명중률/AP/엄폐 규칙 추가의 근거가 아니다.

## 후속 UX 설계

1. 광역 공격을 선택했을 때 대상 수·격파 예상·아군 피해·반격 위험을 요약한다. 실제 예측 모델을 사용하고 상세 조회를 보존한다.
2. 6명 정비에서 구매 후 장착 동선을 줄이고 캐릭터 전환 시 미적용 초안 보존/폐기를 분명히 한다. 이는 이번 자료에서 실행 가능한 게임 기능으로 구현한 것이 아니다.
3. 상점 구매 비교도 합류 동료만 사용하도록 일관되게 필터한다. 현재 캠페인에 효과 없는 임무 변형 옵션을 정리하고 게임패드 포커스를 공간 방향에 맞춘다.

1024×768 게임 UI에서는 글자를 일괄 축소하지 않고 전투 명령/예측의 상황별 전환, 편성 3×2와 축약 상세, 장비 모델 접기와 비교/확정 유지로 대응한다. 이는 후속 구현 사양이며 해당 해상도의 게임 화면 시안이나 구현 검증은 아니다. HTML 비교 페이지의 반응형 동작 확인과 구분한다.

## 제작·검수

- 모드: built-in `image_gen`. CLI/API fallback을 사용하지 않았다.
- 최초 프롬프트: [prompts.json](prompts.json). 선택 결과의 보정 프롬프트: [revision-prompts.json](revision-prompts.json).
- 전투 최초 생성본에서 일부 아군 누락/변형을 확인해 크레스·민트·벨벳·파라·티아·제이드 6명으로 보정했다. 편성의 강한 청록 광채도 완화했다. 미선택 생성본은 이 폴더에 포함하지 않는다.
- 현재 캡처 3장과 원본의 SHA-256 동일성, 이미지 6개의 브라우저 로드, 보기 전환, 원본 확대, Esc 닫기와 포커스 복귀를 확인했다.
- 브라우저에서 실제 비교 화면을 육안 점검했다. 작은 브라우저의 비교 사진은 세로 배치하고 원본 확대를 제공한다. 검수 상세와 파일 해시는 [validation.json](validation.json)을 따른다.
- 문서·디자인 이미지 변경이므로 Unity 테스트/Windows 빌드를 실행하지 않았다. 실제 게임의 전장 가독성, 클릭 편의성, 6인 장시간 정비 성능은 구현 이후 다시 확인해야 한다.
