# TalesTactics

Unity **6000.6.0f1** / URP **17.6.0** / Windows 기반 2.5D 턴제 전술 RPG입니다. 현재 플레이 범위는 **경계를 잇는 의지 메인 20화**, **동료 10명의 개인 이야기 30단계**, **전용무기 10종**, **고유 보스 20종과 보스 기술 60개**입니다. 기존 6장 캠페인은 현재 플레이에서 제외되며, 이전 저장의 성장·장비·완료 이력은 보존합니다.

## 처음 플레이하기

1. **타이틀 화면**에서 **새 게임** 또는 **저장된 게임 불러오기**를 선택합니다. 새 게임은 빈 슬롯을 클릭하고 확인하면 메인 1화의 거점으로 이동합니다. 기존 슬롯은 덮어쓰기 확인을 거치며 이전 저장을 백업합니다. 불러오기에서는 거점 또는 중단한 전투를 이어합니다. 새 메인 1화는 크레스·민트로 시작하고 동료는 이야기에 따라 합류합니다.
2. 처음이라면 상단 **처음 플레이 · 도움말 → 입문 연습 시작**을 선택하세요. 이동 → 공격 → 민트의 회복 → 대기 방향 확정을 직접 연습합니다. 별도 Lv1 전장이며 성장·장비·골드·편성은 저장하지 않습니다.
3. 거점의 **편성**에서 모델을 눌러 동료를 조회하고 **출전 추가/제외**로 인원을 정합니다. 목록 위에서 **마우스 휠을 아래로 내리면** 다음 동료들이 보입니다. 선택·출전 변경 후에도 보던 위치를 유지합니다. 최대 6명이며 해당 메인 임무에서 합류한 동료만 출전할 수 있습니다. 병과 필터·정렬·추천 편성과 프리셋도 제공합니다.
4. **장비·상점·성장**에서 정비합니다. 거점의 동료 초상화를 누르면 해당 캐릭터의 장비 화면으로 바로 이동합니다.
5. **출전 준비**는 완료 기록을 기준으로 다음 메인 임무를 자동으로 표시합니다. 왼쪽 **목표·적 정보**에서 승패 조건과 실제 전장 미리보기를 확인하고, **이야기 시작**을 누르면 대화 후 전투로 이어집니다. 이전 임무를 고르는 단계는 없습니다.

Lv25 전투 훈련은 **편성 → 훈련 · 전투 설정**에서 선택합니다. 일반 기술과 선택한 훈련 목표를 연습할 수 있으며 성장·골드·완료 보상은 저장하지 않습니다. 캠페인으로 돌아갈 때 같은 화면에서 모드를 전환하세요.

## 캠페인·개인 이야기·대화

메인 임무는 순차 해금됩니다. 전투 중 **임무 · 적 정보**에서 현재 목표, 적의 기술과 대응법, 구조 신호·장치·보스 예고를 확인하세요. 임무마다 승패 조건이 달라 적 전멸만으로 끝나지 않는 전투도 있습니다.

**출전 준비 → 동료의 이야기**에서 캐릭터별 세 단계를 선택합니다. 개인 대화 → 구조 순서 선택 전투 → 전용무기 시련 순서입니다. 메인 진행과 앞 단계 완료에 따라 열리며 필요한 완료 화가 화면에 표시됩니다. 첫 단계는 대화로 진행합니다. 구조 순서를 골라도 두 길을 모두 도울 수 있고, 완료 보상은 한 번만 받습니다. 전용무기 없이도 메인 결말에 도달할 수 있습니다.

대화 화면은 초상화·화자·진행 수를 표시합니다. **다음 / 이야기 마치기**, **대화 기록**, **자동 OFF/ON**을 사용할 수 있습니다. 기본 다음 버튼 선택 상태에서는 Space로 진행하고, Tab으로 메뉴를 고른 뒤 Enter로 실행할 수 있습니다. 대화 기록을 열거나 창이 비활성화되면 자동 진행이 멈춥니다.

**출전 준비 → 전투 전 이야기 → 전투 → 결과의 계속 → 전투 후 이야기 → 다음 장 준비** 순서로 진행합니다. 결과는 캐릭터 초상화, 성장량, 아이템 그림과 수량으로 표시합니다. 보상 저장 후에는 후일담 진행 위치도 저장하므로 다시 실행해도 이야기를 이어 읽으며 보상을 중복 지급하지 않습니다. 메인 20화 완료 후에는 메인 완료 상태를 표시하며 동료 이야기와 정비는 계속 사용할 수 있습니다. [캠페인·보스·시련의 구현 범위](Docs/CrossoverStatus/README.md)

편성·장비·성장·개인 이야기와 구매 비교에는 합류한 동료만 표시합니다. 편성은 3열 세로 스크롤로 탐색하며, 전투 결과의 성장 카드는 6명(2열×3행)까지 표시합니다. 장비·성장 캐릭터 목록은 6명 단위로 넘깁니다. 전투 상단은 아군 초상화와 **임무 / 설정** 중심으로 구성하고, 선택 캐릭터 정보와 명령은 왼쪽에 모았습니다. 카메라는 전장 위에서 휠·Q/E·Home으로 조작하고, 행동 경험치 알림은 화면 중앙에서 순서대로 표시합니다.

## 전투와 조작

기본은 **아군 턴 자유 선택 → 적군 턴**입니다. 명령 대기 중 미완료 아군을 바꿔 가며 조작할 수 있고, 이동·행동 기록은 유지됩니다. 각 아군은 이동과 행동을 한 번씩 사용하며 순서는 자유입니다. 일부 캐릭터의 추가 연계는 기술별 조건을 따릅니다.

- **이동** → 유효한 타일 클릭. 아군 칸을 통과할 수 있고 빈 칸에 도착합니다. 경로와 도착 모델을 미리 표시하며 이동 후 행동하기 전에는 취소할 수 있습니다.
- **공격·기술** → 대상에 마우스를 올려 예측 확인 → 유효한 대상 클릭으로 즉시 사용합니다. Tab으로 고른 대상에는 Enter를 누릅니다. 별도 실행 버튼은 없습니다.
- **대기·방어** → 머리 위 4방향 화살표로 방향 확정. 방어는 행동을 사용해 받는 피해를 줄입니다. 완료한 아군은 채도가 낮아지고 다음 아군 턴에 복원됩니다.
- **아군 턴 종료**는 확인 후 미완료 아군을 모두 대기시킵니다. 기존 방향을 유지하며 방어 효과를 추가하지 않습니다.
- **능력**은 능력치·현재 상태·기술·장비를 보여 줍니다. **사용 가능 / 전체 조회**로 잠긴 기술의 조건도 확인합니다. 위험 범위와 황색 공격 예고, 높이·시야·방향에 따른 피해 예측을 함께 살피세요.

| 입력 | 기능 |
|---|---|
| 마우스 클릭 / 우클릭 | 선택·즉시 사용 / 한 단계 취소 |
| 전장 위 휠 | 확대·축소 |
| M / A / S / G / W | 이동 / 공격 / 기술 / 방어 / 대기 |
| Z / V | 이동 취소 / 적 위험 범위 표시 |
| 방향키 / Enter / Esc | 타일 선택 / 선택·사용 / 취소 |
| PgUp / PgDn | 자유 턴의 미완료 아군 선택 |
| Tab / Shift+Tab | 다음·이전 대상 또는 메뉴 선택 |
| Q / E / Home | 카메라 회전 / 전체 보기 |
| F1 / F5 | 도움말 / 저장·설정 메뉴 |
| Space | 파라 타이밍 입력 / 대화의 다음 진행 |
| 패드 왼쪽 스틱 / 방향키 | 커서 / 메뉴 순환 |
| 패드 A·× / B·○ | 선택·타이밍 / 취소 |
| 패드 LB·RB / LT·RT | 카메라 회전 / 대상 순환 |
| 패드 오른쪽 스틱 / R3 | 확대·축소 / 전체 보기 |

메뉴 밖 빈 곳 클릭도 한 단계 취소하며, 이동 직후 행동 메뉴에서는 이동을 되돌립니다. 유효한 이동 칸·대상 클릭은 선택이 우선입니다. 진행 중인 행동 연출은 취소할 수 없습니다.

궁극기는 해금 레벨·MP·SP·고유 조건을 모두 만족해야 합니다. 파라는 모든 일반 기술 해금 후 사자전후의 회전 진행률 40–75% 구간에 Space 또는 패드 A를 입력해 연계합니다. 자동 타이밍은 **저장 · 설정 → 설정**에서 선택하고 저장할 수 있습니다. 정확한 비용·연계 조건은 게임의 기술 상세와 도움말을 확인하세요.

## 장비·성장

**장비 → 캐릭터 → 슬롯 → 후보 선택 → 장착하고 저장**으로 교체합니다. 현재 장비와 변경 초안을 나란히 비교하며 **전체 능력치 보기**에서 전체 비교를 엽니다. 캐릭터·정비 메뉴를 바꿔도 각 캐릭터의 초안은 유지됩니다. **변경 취소**는 현재 캐릭터의 초안만 버립니다. 초안은 저장 파일에 기록되지 않으므로 타이틀·다른 저장 슬롯·게임 재실행에서는 유지되지 않습니다.

개인 시련에서 얻은 **전용무기 10종**은 각 소유자만 장착할 수 있습니다. 고유 아이콘·효과와 장착 외형을 제공하며, 후보 선택 시 외형을 미리 봅니다. 저장 후 편성·상태창·전투의 방향별 동작·이동 도착 모델에 반영되고, 해제하거나 일반 무기로 바꾸면 기본 외형으로 돌아갑니다. 전용무기는 상점 구매·매각 대상이 아닙니다.

상점 재고는 장착 중인 수량을 포함해 파티가 공유합니다. 미장착 수량만 매각할 수 있으며, 상품의 잠금 조건·가격·거래 후 잔액은 상점에서 확인하세요. 구매 비교에는 합류했고 해당 장비를 사용할 수 있는 동료만 표시합니다. **구매 · 바로 장착**은 선택한 동료에게 구매와 장착을 함께 저장합니다. 저장에 실패하면 골드·재고·장비를 모두 이전 값으로 되돌립니다.

공격·유효 회복·지원·처치로 개별 EXP를 얻고 100 EXP마다 레벨업하며 Lv50이 상한입니다. 승리 시 전투 성장과 임무 EXP를 확정합니다. 재도전·저장 없이 나가기에서는 이번 전투 성장을 취소합니다.

**성장**에서는 레벨·EXP·승급·전술 특성을 확인합니다. Lv10부터 성장 방향을 선택할 수 있습니다. **합류 훈련**은 선택한 해금 임무의 권장 진입 레벨까지 올리고 저장하므로, 보상이 없는 Lv25 전투 훈련과 구분하세요. 승급은 캐릭터의 레벨 조건과 메인 6화 완료가 필요하며, 이전 저장의 스토리 조건 충족도 인정합니다.

## 저장·설정·되돌리기

타이틀의 **저장된 게임 불러오기**에서 저장 슬롯을 선택합니다. 빈 슬롯은 새 게임에서 사용할 수 있습니다. 손상·미지원 저장은 원본 보호 안내를 표시하며 덮어쓰기를 차단합니다. 거점의 **저장 · 설정 → 저장 후 타이틀로**로 돌아갈 수 있습니다.

거점 상단 **저장 · 설정** 또는 전투 중 **설정(F5)**에서 관리합니다. 화면에는 **저장 / 설정 / 전투 / 조작** 탭이 있습니다.

- **저장**: 준비 중 3개 슬롯 불러오기, 현재 슬롯 저장, 중단 전투 이어하기. 보상·거래·장비·승급 등은 확정할 때 저장합니다.
- **저장 후 나가기**: 캠페인의 아군 명령 대기 중 전투를 중단 저장합니다. 이어한 뒤 나갈 때도 다시 저장하세요. 구 6장 중단 전투는 이어할 수 없습니다.
- **되돌리기**: 전투당 3회, 직전 행동 전으로 돌아가며 이후 적 행동·확률도 함께 되돌립니다. 사용 횟수와 기록을 중단 저장에 보존합니다. 훈련·연출 중·승리 후에는 사용할 수 없습니다.
- **재도전**: 출전 당시 편성·장비·레벨·규칙으로 다시 시작합니다. 저장된 캠페인 성장·골드·장비는 유지됩니다.
- **설정**: 화면·음량·패드 커서·자동 타이밍·다음 전투 턴 순서/AI·효과 표시량. 적용·저장하지 않고 닫으면 취소됩니다.
- **전투**: 난이도, 반격·지원, 적 행동 속도 1/2/4배와 간략 연출. 난이도·반응 공격은 다음 출전부터 적용되며 이어하기·재도전은 출전 당시 규칙을 유지합니다. 현재 메인·개인 임무에 효과가 없는 구 캠페인용 임무 변형 옵션은 해당 화면에서 숨깁니다.
- **조작**: 글자 최대 크기 100/115/130%와 조작 안내.

저장은 Unity `Application.persistentDataPath` 아래 `campaign.json`, `campaign-slot2.json`, `campaign-slot3.json`과 설정 파일에 보관됩니다. 현재 캠페인 형식은 V3, 중단 전투는 V11입니다. 유효한 백업이 있으면 복구하며, 손상·미지원 새 버전은 원본 보호를 위해 저장을 막을 수 있습니다. 저장 실패·보호 안내가 보이면 확인하고 재시도하세요. ## Unity에서 실행·개발하기

1. 이 저장소 폴더를 Unity Hub에 기존 프로젝트로 추가하고 **6000.6.0f1**으로 엽니다. 최초 패키지 설치·import를 기다립니다.
2. `Assets/TalesTactics/Scenes/TestBattle.unity`를 열고 Play를 누릅니다. 타이틀 화면에서 시작합니다.
3. 현재 `Content`는 실제 조정된 에셋입니다. **Create Test Battle / `DemoContent.Create`를 다시 실행하지 마세요.** 캐릭터·스킬·장비 수치 변경은 해당 에셋을 편집합니다. 기존 원화·모션·카탈로그를 초기 생성기로 덮어쓰지 않습니다.

기본 개발 브랜치는 **develop**입니다. 별도 작업 브랜치가 필요하면 최신 develop에서 만들고 완료 후 develop에 통합합니다. **main은 검증된 스냅샷 보관용**이며 사용자의 릴리즈·main 반영 요청이 있을 때만 갱신합니다. 기존 Unity Editor·게임 프로세스와 사용자 저장을 보존합니다.

| 확인 | 방법 |
|---|---|
| Unity 엔진 테스트 | Window → General → Test Runner의 EditMode / PlayMode |
| API 참조 컴파일 | Unity import 후 `./Tools/CompileApi.ps1` |
| 엔진 독립 규칙 확인 | `./Tools/ManagedChecks/Run.ps1` |
| Windows 빌드 | 기존 TestBattle 씬 확인 후 Tales Tactics → Build Windows Player |

PlayMode의 화면 검수는 그래픽 Editor나 Windows 플레이어에서 수행합니다. `WaitForEndOfFrame`을 쓰는 검사를 배치 모드 결과로 대체하지 않습니다. API 참조 컴파일과 ManagedChecks는 **Unity 테스트 결과가 아닙니다**.
