# TalesTactics — 개발 시작 안내

Unity 6000.6.0f1 / Windows / URP 17.6.0 기반 2.5D Tactical RPG 프로젝트입니다.

## 현재 상태

6장 캠페인과 전투·성장·장비·저장 시스템을 구현했습니다. **실제 Unity EditMode 95개·PlayMode 58개를 통과했습니다.** 기존 영웅 10명 모두를 특징을 유지한 3등신 고밀도 픽셀 아트로 교체하고, 방향별 보행 4프레임·궁극기 전용 준비/발동 동작을 연결했습니다. 일반 적 9종과 최종 보스 다오스, 16종 전장 재질·16종 장식·6장별 원경을 적용했습니다. 실제 화면과 상세 범위는 [픽셀 아트 개편](Docs/PixelCampaign/README.md)을 참고하세요. 기존 89개 기술 연출과 오리지널 음악 14곡은 유지합니다. 전체 게임 완성본이나 전문가의 원작 작화 승인을 뜻하지 않으며, 최신 빌드·실행 검증과 한계는 Docs/VALIDATION.md를 따릅니다.

- 런타임·에디터·테스트 C#을 설치된 Unity 실제 API DLL로 각각 컴파일: 통과.
- 엔진 독립 규칙 테스트 93개: 통과. Unity API 일부를 대체한 별도 .NET 테스트입니다.
- API 검사는 현재 프로젝트의 Library DLL을 사용합니다. 실제 실행 검증과 한계는 Docs/VALIDATION.md에 기록했습니다.
- 6번 입력·배포 구현 완료: 게임패드 조작 및 배포용 한국어 폰트·라이선스 포함. 가상 Gamepad와 Windows 플레이어 검증을 통과했으며 실제 기기별 검수는 별도입니다.
- 새 아트의 Windows 1~6장 대표 화면과 마우스 이동·취소·공격 미리보기·카메라 검수를 완료했습니다. [실행 화면과 검수 범위](Docs/PixelWindowsReview/README.md)를 참고하세요.
- 6장에서 기본 공격·마신검·회복·다오스 블래스트와 재출전을 직접 확인했습니다. [대표 전투 연출 검수](Docs/PixelCombatReview/README.md)에 실제 발동 화면과 확인 범위를 기록했습니다.

현재 캠페인은 **6장까지** 플레이할 수 있습니다. 유적 → 협곡 → 관측소 → 수문 → 중계핵의 첫 여정을 완결했습니다. 장 목록을3개씩 넘겨 순차 해금한 장을 선택합니다. 수호의 메달·단련 갑옷과 최초/반복 보상, 기존V2 저장 연계를 지원합니다. 전체 장 구성은 [CAMPAIGN.md](Docs/CAMPAIGN.md)를 참고하세요.

20종 전체에 중간 동작320개를 추가하고 기본 공격4·일반 기술5·궁극기4프레임을 연결했습니다. [중간 동작 및 외형 검수](Docs/AnimationPolish/README.md)에서 4방향 실제 렌더링을 확인할 수 있습니다.

전투 UI는 작은 캐릭터 요약창과 별도 능력창, 캐릭터 옆 명령·오른쪽 기술·하단 실행/취소 배치로 개편했습니다. [실제 UI 화면](Docs/CompactHud/README.md)을 참고하세요.

전장 전체/현재 유닛 보기, 대상 순환과 3열 편성·장비 비교·통합 상점 UI를 적용했습니다. [화면과 조작 안내](Docs/ReleaseUi/README.md)를 참고하세요.

## 실행

1. Unity Hub에서 이 README가 있는 `TalesTactics` 폴더를 기존 프로젝트로 추가합니다.
2. 설치된 **6000.6.0f1**으로 엽니다. 패키지 다운로드와 최초 import를 기다립니다.
3. 포함된 `Assets/TalesTactics/Scenes/TestBattle.unity`를 엽니다. 현재 Content는 아트·전투 튜닝이 적용된 실제 에셋이므로 **Create Test Battle / DemoContent.Create를 다시 실행하지 않습니다.**
4. Play를 눌러 출전 화면에서 1–6명을 선택하고 **전투 시작**을 누릅니다. 기본 선택은 크레스·민트·파라, 적은 4명입니다.
5. 모든 일반 스킬은 **훈련: Lv25** 모드로 확인합니다. 일반 모드는 Lv1부터 저장된 성장치를 사용합니다.

`Launch.ps1`은 설치된 에디터에서 프로젝트를 여는 선택적 편의 스크립트입니다. 테스트 Scene은 기존 사용자 작업을 자동으로 덮어쓰지 않습니다. 생성 이후 수치 변경은 Content의 asset을 편집하세요. 생성기 코드는 초기 데이터의 출처이며 기획 원본은 Docs/GAME_DESIGN.md입니다.

최신 UI Windows 실행 파일: `Builds/WindowsReleaseUi/TalesTactics.exe`. 이전 실행 중인 플레이어와 파일 충돌을 피하려고 별도 폴더에 빌드했습니다. Builds 폴더는 Git에서 제외됩니다.

## 조작

게임패드: 왼쪽 스틱으로 화면 커서 이동, 방향키로 메뉴 순환, A/× 선택·타이밍 입력, B/○ 취소, LB/RB 카메라 회전, 오른쪽 스틱 확대/축소, R3 초기화. 마우스와 자동 전환됩니다. 상세 조작·폰트 출처·검증 범위는 [입력·배포 안내](Docs/INPUT_DISTRIBUTION.md)를 참고하세요.

- Move → 청색 테두리 타일 클릭: 경로를 따라 이동. Undo Move로 원위치 복귀. 공격 사거리는 적색, 선택한 효과 범위는 굵은 금색 테두리로 표시합니다.
- Attack → 타일 선택 → 피해/효과 Preview → 실행.
- Skill → 스킬 상세(비용·사거리·효과·사용 조건) → 목표 선택 → 타일 선택 → 실행. 잠긴 스킬도 상세를 열어볼 수 있습니다.
- 이동과 행동 순서는 자유. 공격 후 이동도 가능. 이동 뒤 행동하면 이동 취소가 잠깁니다.
- Wait 또는 Guard → Front/Back/Left/Right 선택 → 턴 종료.
- 파라의 사자전후: 모든 일반 기술 해금, MP50 이상일 때 회전 진행률 40–75%에서 Space 또는 버튼 입력. 성공하면 MP50의 사후폭쇄진, 실패하면 사자전후만 실행. 자동 입력 옵션 제공.
- ESC: 선택 취소. 진행 중인 연출·적 턴은 취소하지 않습니다.
- 승패 화면에서 Restart → 출전 화면. KO는 다음 전투에서 회복됩니다.

## 확장 지점

- CharacterData: 초상화, Front/Back/Left/Right Sprite, Poses(공격/시전/방어/피격 및 보행/쓰러짐/기술/궁극기 방향별 프레임), Animator, 능력치/성장, 스킬, 승급, 테마.
- Animator를 연결할 경우 Int 파라미터 `Facing`, `Action`을 Definitions.cs enum 값에 맞춥니다.
- CharacterData.VisualStyle은 캐릭터 효과 유형, SkillData.VisualStyle은 기술별 재정의입니다. Automatic은 캐릭터/무기 기본값을 사용합니다.
- SkillData: MP/HP/게이지, 사거리, 범위, 속성, 대상, 복수 효과, 해금 레벨, 연계 조건. Presentation은 효과 패턴·시각 반복·준비/복귀 시간·크기이며 전투 판정 횟수는 바꾸지 않습니다.
- AudioLibrary: battle/victory/boss/story 및 10명 테마 ID에 프로젝트 오리지널 14곡을 연결했습니다. 제공 음원으로 교체할 수 있습니다. 2장은 boss(누락 시 battle), 궁극기는 테마를 재생한 뒤 이전 음악 위치로 복귀합니다. 음악 음량 기본값은 0.28입니다. 출처/제작법은 Docs/ORIGINAL_MUSIC.md를 참고하세요.
- 저장: Unity persistentDataPath 아래 campaign.json, 교체 시 .bak 보관. 훈련 모드에서는 경험치를 저장하지 않습니다.
- 배포용 Noto Sans CJK KR 폰트와 라이선스를 포함했습니다. BattleHud.Font를 지정하면 사용자 폰트를 우선하며 미지정 시 포함 폰트를 사용합니다. 운영체제에 한국어 폰트가 없어도 표시할 수 있습니다.

## 검증 명령

- 엔진 독립: PowerShell에서 `./Tools/ManagedChecks/Run.ps1`
- Unity: Window → General → Test Runner → EditMode → Run All.
- Scene 검증 후 빌드: Tales Tactics → Build Windows Player.
- 정적 API 검사: 최초 Unity import 후 `./Tools/CompileApi.ps1`.

구현 구조, 현재 한계와 다음 작업은 Docs/ARCHITECTURE.md 및 Docs/TODO.md를 확인하세요.

카메라: 유닛 정보 아래 좌회전/우회전, 확대/축소, 초기화 버튼을 사용합니다. 전장 위 휠로 확대/축소할 수 있습니다. Q/E와 Home 단축키도 제공합니다. 세로 창에서는 정보·명령 패널을 전장 아래에 배치합니다.


출전 준비 → 장비 관리 → 캐릭터 → 슬롯을 눌러 교체/해제 → 적용 · 저장. 미적용 변경은 돌아가면 취소됩니다. 출전 준비 → 장비 상점에서 청동검(100G), 가죽 갑옷(150G), 생명의 부적(100G)을 구매합니다. 보유 수량은 장착 중인 장비를 포함해 파티가 공유하며, 다른 캐릭터가 모두 장착한 장비는 선택할 수 없습니다. 초기 소지금은 300G와 청동검 1개, 캠페인 최초 승리 골드는 장별120/180/240/320/420/560G, 반복은 그 절반입니다. 훈련에서는 구매·골드 보상을 막습니다.

저장 오류 시 출전 화면에 안내가 표시됩니다. 유효한 .bak가 있으면 자동 복구하며, 복구 불가/미지원 새 버전은 원본 보호를 위해 저장하지 않습니다. 이 경우 플레이 중 진행은 보존되지 않습니다. 원본을 백업하고 호환 버전 또는 유효한 저장 파일을 복원한 뒤 재실행하세요.

출전 준비 → 성장 · 승급 → 캐릭터에서 저장된 레벨/EXP, 승급 조건과 능력치 변화를 확인합니다. 캠페인 모드에서 레벨·스토리 조건을 만족하면 승급 · 저장을 사용할 수 있습니다. 캠페인 1장 승리로 2장을 해금하고 2장 승리로 스토리 조건을 충족합니다. 1~6장은 각 전용 맵을 사용하며 훈련 레벨로 승급할 수 없습니다.

Windows 캠페인 자동 검수: `Docs/PLAYER_REVIEW.md`의 별도 개발 빌드를 만든 뒤 `./Tools/RunCampaignReview.ps1`을 실행합니다. 새 GUID 슬롯에서 여섯 장 승리·프로세스 재실행·정상 패배·저장 불변을 확인하며 기존 사용자 저장은 보존합니다. 수동 마우스/시각 검수와는 별개입니다.

화면 기반 추가 검수도 완료했습니다. 두 장 캠페인 완주, 상점·보상·장비·성장, 패배/재출전과 저장 복원, 전체 기술 UI 자동 검사, 장시간 성능 측정의 증거와 한계는 [FINAL_REVIEW.md](Docs/FINAL_REVIEW.md)를 참고하세요.

저장 버전 2: 기존 Version 1의 레벨·경험치·승급·장비·완료 기록을 유지하고, 장착 중인 장비 수량 이상을 보유 수량으로 이관합니다. 읽을 때는 파일을 바꾸지 않으며, 첫 저장 시 원본을 campaign.json.v1.bak로 보존합니다. 신규/이관 캠페인 모두 300G와 최소 청동검 1개를 갖습니다.

장비 매각: 출전 준비 → 장비 상점 → 장비 매각에서 미장착 장비를 1개씩 팔 수 있습니다. 매각가는 구매가의 절반(소수점 버림)이며 청동검/부적은 50G, 가죽 갑옷은 75G입니다. 장착 중인 장비, 훈련 모드, 저장 보호 상태, 골드 상한 초과 시에는 매각을 막습니다. 저장 실패 시 수량과 골드를 복원합니다.

1장 완료 후 철검(240G, STR+8)과 강화 갑옷(300G, HP+35/DEF+6)을 구매할 수 있습니다. 완료 전에는 상품 상세에서 해금 조건을 확인할 수 있습니다. 해금은 저장된 완료 기록을 사용하며 기존 저장에도 적용됩니다.

캠페인 승리 시1장 생명의 부적,2장 철검,3장 강화 갑옷,4장 수호의 메달,5장 단련 갑옷,6장 수호의 메달을 각각1개 확정 지급합니다. 반복 승리에서도 획득하며 같은 전투의 저장 재시도는 중복 지급하지 않습니다. 장비별 99개 상한에서는 해당 장비만 미지급하고 결과에 안내합니다. 훈련·패배에서는 지급하지 않습니다.

캠페인 시작 시 전투 전 이야기가 표시됩니다. 다음 대사/이야기 마치기 또는 건너뛰기로 전투에 진입합니다. 보상 저장에 성공한 승리 화면에서 전투 후 이야기를 읽을 수 있습니다. 출전 화면의 이야기 버튼으로 다시 읽어도 보상이 추가되지 않습니다. 훈련은 기존 10×9 테스트 맵과 즉시 전투 진입을 유지합니다. 대사는 프로젝트용 창작 시나리오이며 최종 캐릭터 아트·음성은 포함하지 않습니다.


캠페인 구성과 편집 위치는 Docs/CAMPAIGN.md에 정리했습니다.

스킬 기하 규칙: 피어싱 라인은 상하좌우 직선 관통(사거리4), 쌍장저파는 방향형 부채꼴(사거리3)을 사용합니다. 해당 기술과 나탈리아/시온의 기본 공격은 장애물·높은 지형 뒤를 공격할 수 없습니다. 높이 차 제한은 상세에 표시됩니다. 방향형 기술은 상하좌우 타일을 선택하며 노란 영향 범위와 실제 대상 판정은 같은 규칙을 사용합니다.

전체 89개 기술에 기하·높이·시야·속성 규칙을 적용했습니다. 물리 피해는 높이 1단계당 ±10%(최대 ±20%), 활/총 물리 기술은 높이에 따라 사거리 최대 ±2칸입니다. 속성 저항/약점은 피해 미리보기에 배율로 표시하며 회복에는 적용하지 않습니다. 전체 수치표는 Docs/COMBAT_BALANCE.md를 참고하세요. 캠페인은 6인 출전을 권장하며 3인 기본 공격 자동 전투는 두 장 모두 패배했습니다.
